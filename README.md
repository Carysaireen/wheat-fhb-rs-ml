# 小麦赤霉病多光谱特征降维与病情严重度建模

用多光谱冠层特征判断小麦是否感染赤霉病（FHB, Fusarium Head Blight），并估计病情严重度 DI。
数据规模是 165 个样本、117 维特征，典型的高维小样本场景。

项目当前的主线工作想研究一个问题：
**在这批数据上，「少量特征 + 简单模型」得到的高性能，有多少是真的？**
为此把评估口径从随机交叉验证换成跨区域验证，并搭了一套逐条对比的评审机制。
结论是：换口径之后，绝大多数好看的组合都掉下来了，而只有一组站得住。

---

## 数据

`data/raw/Wheat_Scab_Features_Extraction_Ordered_region.csv`，GBK 编码，165 行 × 126 列。

- 前 9 列是元信息，第 10 列起为 117 维特征：植被指数、波段统计量、GLCM 纹理；
- 标签 `Unnamed: 2`：0 = 健康（90 例），1 = 患病（75 例）；
- `DI` 是 0–100 的目视估读病情，`O_Lat` / `O_Lng` 是采样点经纬度；
- **标签由 DI 的硬阈值给出**（0 ⟺ DI ≤ 30，1 ⟺ DI ≥ 35），所以分类和回归是同一个量的两种粒度；
- 划分固定为 132 训练 + 33 封存测试。测试集全程未参与任何调参或选择，只在最后评估一次。

样本在空间上高度共址：最近邻距离中位数约 45 m，149/165 个样本在 110 m 内就有邻居。
也就是说，一行记录并不等于一个独立的空间单元。

## 为什么要换评估口径

随机分层的 5 折交叉验证隐含一个假设：样本之间可以互换。这批数据不满足这个假设。
同一个田块里的样本特征相近、病害程度也相近，随机折会把「空间记忆」当成模型的泛化能力，
于是所有方法看起来都不错，而差距被系统性抹平。

对照做法是按位置分块（spatial block CV）：先用 `KMeans(k=10)` 对经纬度聚类得到空间块，
再用 `StratifiedGroupKFold(3)` 把整块留出，保证同一块内的样本不会同时出现在训练和验证里。
两种口径并排跑，差值就是随机折里那部分乐观水分。

实测（`src/spatial_group_cv.py`，主口径 k=10，3 个分区种子）：

| 任务 | 模型 | 随机折 | 空间折 | 差值 |
|---|---|---|---|---|
| 分类 | LR | 0.7125 | 0.5881 | +0.1244 |
| 分类 | RF | 0.7521 | 0.6792 | +0.0729 |
| 分类 | SVM | 0.7826 | 0.7293 | +0.0534 |
| 回归 | RF | 0.3942 | −0.2957 | +0.6900 |
| 回归 | Ridge | 0.0724 | −1.4813 | +1.5537 |
| 回归 | SVR | 0.1690 | −0.7374 | +0.9064 |

分类掉 5–12 个百分点，回归直接由正转负。后面所有实验都同时报这两种口径，
并以空间折为准。

## 擂台机制

项目设置了一个固定标杆（擂主），其余组合逐条向它发起挑战。

- **擂主**：双特征 `current_2` = `NREDI1` + `NDVIre2`，它是早期特征优选得到的「黄金双特征」；
- **挑战者**：9 种特征选择器 × 14 种模型 × 特征数 K ∈ {5, 10, 20, 30}，双重采样口径；
- **判定**：每条挑战算一个差值 Δ，与最小可分辨差比较。

  最小可分辨差取
  `MDD = max(2√2·σ_seed / √n_folds, 1/n_valid_min)`
  
  即「跨分区种子的波动」和「单个验证样本占的刻度」中较大的那个。
  `|Δ| ≤ MDD` 记为平局（TIE），否则判胜（WIN）或负（LOSE）。
  **这个门槛只由擂主自身的波动决定**，挑战者的波动只作诊断披露——否则波动越大的挑战者越容易「不被判负」。

两个关键约束：特征选择在每一折的训练部分内完成（验证折从不参与选择），
预处理（中位数填补、IQR 截断、标准化）绑在模型 Pipeline 内部逐折拟合。

结果：

| 阶段 | 比较次数 | 胜 | 平 | 负 |
|---|---|---|---|---|
| 擂主档案（默认超参） | 分类 72 / 回归 95 | 0 / 0 | 9 / 0 | 63 / 95 |
| 调优后全矩阵 | 分类 440 / 回归 360 | 0 / 0 | 132 / 0 | 308 / 360 |

**一次胜利都没有。** 调参把平局数从 9 提到 132，但没有造出一个胜者；
回归轨在空间折下 360 次全部判负，且 R² 最好的一次仍是 −0.0362，一个正值都没有。

这里必须配多重比较：440 次比较若不做校正，至少出现一个假胜者的概率接近 1.000。
Bonferroni 校正后的单次显著性水平是 1.14e-04，本项目的判定结果在这个水平下依然成立。

## 结果

### 分类

跨 3 个空间分区种子，`current_2` 上各模型的准确率：

| 模型 | 空间折准确率（3 种子均值） | 最差种子 |
|---|---|---|
| **NB** | **0.8141** | **0.8078** |
| SVM / SVMLin | 0.8114 | ~0.76 |
| LDA / PLSDA | 0.8015 | 0.7597 |
| ET | 0.7934 | — |
| RF | 0.7889 | 0.7119 |
| XGB | 0.7862 | — |
| LR | 0.7807 | — |

注意均值之外的第二列。LDA、PLSDA、RF 在单个种子上都能跑到 0.8331（高于 NB 的 0.8227），
但换一个空间分区方式就掉到 0.71–0.76。**NB 是唯一「均值最高且最差种子也最高」的模型。**

结论：分类基线写「双特征 + 朴素贝叶斯，跨区域准确率 0.814，尚未被任何选择器×模型组合超越」。

### 回归

`current_2` 加 XGB，空间折 R² = 0.1215（3 种子均值，最差 +0.0296）。
换用其他任何模型，跨种子均值都变成负数。

回归是这批数据上的硬约束：DI 是 0–100 的连续量，而可用的判别信息主要来自少数几个红边指数，
不足以支撑连续梯度的拟合。

## 朴素贝叶斯为什么站得住

NB 在高维小样本里反复跑到最前，值得单独查清，不能只当成巧合。
`src/diagnose_nb.py` 把特征数 K 从 2 扩到 30，逐折记录混淆矩阵和预测分布，结果如下。

**K 曲线**（空间折准确率，跨 3 种子 × 3 选择器求均值）：

| 模型 | K=2 | K=5 | K=10 | K=20 | K=30 | K2→K30 |
|---|---|---|---|---|---|---|
| NB | 0.8141 | 0.6975 | 0.7346 | 0.7674 | **0.7778** | −0.0363 |
| ET | 0.6939 | 0.7040 | 0.7083 | 0.7217 | 0.7287 | +0.0347 |
| KNN | 0.7495 | 0.7085 | 0.7635 | 0.7181 | 0.7085 | −0.0410 |
| LR | 0.8023 | 0.6727 | 0.6901 | 0.6695 | 0.6415 | −0.1608 |
| SVMLin | 0.8114 | 0.7061 | 0.7214 | 0.6886 | 0.6180 | −0.1934 |

K=2 时全体都高，因为 `current_2` 本身是人工精选的强特征，不是模型强；
K 加到 5 换成算法筛的特征，所有模型一起掉。K≥5 之后只有 NB 在回升，
K=30 时领先第二名 ET 有 0.0491。

**可解释的机制。** 这批特征高度冗余（relieff 前 5 名的平均 |r| = 0.678），
而且越往后加的特征区分度越低（平均 |Cohen's d| 从 K=2 的 1.238 降到 K=30 的 0.880）。
高容量模型必须去区分一堆「既高度相关、又都很弱」的特征，权重估计的方差随 K 迅速放大，
于是性能反而下降。NB 只估计每个特征的类条件均值和方差，参数量极小，
对特征之间的相关性视而不见——在这个场景下，这个「错误假设」的代价很小。

**空间泄漏随容量的变化**（随机折减空间折的差）：

| 模型 | K=30 的差值 |
|---|---|
| SVMLin | +0.1102 |
| LR | +0.0716 |
| RF | +0.0667 |
| NB | **−0.0108** |

高容量模型越用越多特征，越依赖「区域记忆」；NB 在 K=20/30 上差值为负，是场上唯一一个。

**两个需要说明的点。**

一是条件独立假设。`current_2` 两个特征的相关系数是 0.7621，严重违反 NB 的前提，
但 NB 在 K=2 依然是第一。原因是这两个特征太强了（|Cohen's d| 分别为 1.336 和 1.140，
都超过 1），强到假设错得离谱也压不住信号。所以 NB 的适用边界是**高信噪比特征**，
不是「特征必须独立」。

二是「稳」的确切含义。NB 的折间标准差不是最小的（KNN 0.0259、SVM 0.0300 都比它小），
但它的跨种子最大标准差 0.0664 是全场最小。准确说法是：
NB 不会出现某个分区方式让它崩掉——而 RF（0.1057）和 LR（0.0991）会。

也检查过一种可能的质疑，即 NB 是否只是靠偏向多数类刷准确率。
在诊断集上，NB 预测的正类比例是 0.4909，真实比例是 0.4390，偏差 +0.0519，
比 ET 的 +0.0719 还小；两类召回率的不对称程度 +0.0311 也小于 ET 的 +0.0736。
本数据也不是类别不平衡（多数类占 54.5%）。这个解释不成立。

## 可复现性

项目对可复现性的要求比对性能更严。

**确定性。** 早期用 sklearn 的 `liblinear` 求解 L1 逻辑回归时踩过一次坑：
该求解器对坐标做随机置换且不暴露种子，同一份数据两次拟合会得到数值等价但**排序不同**的解。
选择器按 |系数| 取前 k 个，所以选出的特征集合会变，下游性能跟着变。
更麻烦的是，这种错误产生的结论依然自洽，靠「多做几次实验」发现不了。
现在的做法是统一改用 `saga` 求解器并固定 `random_state`，
并且每个阶段都配一个自校验脚本（`src/selfcheck_*.py`），用同一输入重复跑再逐位比对。

**跨阶段对比的自校验。** 阶段之间共享折向量、选择器实现、打分函数。
每次做「单一变量控制」的对比前，先跑一遍自校验确认新代码在旧参数下能逐位复现旧结果。
这项工作确实抓到过两个缺陷：SVM 的 `probability` 参数不一致导致 `roc_auc` 口径不同，
以及判定门槛的实现让「表现越差反而越安全」。两者都已修正，并验证过不影响已有结论。

**空间折与坐标精度。** 空间折依赖高精度经纬度。对外发布的数据把坐标圆整到 0.01 度（约 1 km），
圆整会改变 KMeans 的分块结果（seed=42 时约 10% 的样本换块），折分配随之变化。
因此 `data/cv/spatial_folds_k10.csv` 直接用高精度坐标算好并发布，
包含三种折形态（分类 132 行、回归 132 行 DI 分箱、回归 116 行 DI>0 子集）。
`src/spatial_folds.py` 会优先读取它，取不到才按坐标现算。
这样既不需要公开原始坐标，也能得到与报告一致的数字。

随机折不依赖坐标，只依赖行序和标签，用公开数据可以直接跑出相同结果。

**折的构造。**

- 分类随机折：`StratifiedKFold(5, shuffle=True, random_state=42)`；
- 回归随机折：`DI > 0` 子集上的 `KFold(5, shuffle=True, random_state=42)`；
- 空间折：`KMeans(k=10)` + `StratifiedGroupKFold(3)`，分区种子 42 / 7 / 2026。

**口径说明。** 报告里凡涉及空间折的数字，都注明是「单种子 + 全矩阵取最大」还是「3 种子均值」。
这两者不可混用：例如 NB 在 K=10/20/30 上的单种子最好成绩是 0.8200 / 0.8149 / 0.8045，
用 3 种子均值重算是 0.7346 / 0.7674 / 0.7778，而且 K=10 时第一名其实是 KNN。

## 复现

```bash
pip install -r requirements.txt

python src/create_split.py            # 划分并封存测试集
python src/create_cv_folds.py         # 生成随机折
python src/spatial_group_cv.py        # 随机折 vs 空间折对照
python src/run_selector_zoo.py        # 选择器×模型 全矩阵
python src/run_champion_profile.py    # 擂主档案
python src/run_stage5_tuned_matrix.py # 调优后全矩阵挑战
python src/diagnose_nb.py             # 朴素贝叶斯诊断
python src/aggregate_best_combinations.py
```

全部脚本都在 `src/` 下运行。加 `--smoke` 或 `--quick` 可以只跑一小部分验证流程。
耗时最长的是 `run_stage5_tuned_matrix.py`（约 23 分钟），其余在 1–7 分钟。

数据里的经纬度已圆整、采集人信息已匿名化，重新生成发布版数据用
`python tools/make_release_data.py`（需要原始的未处理数据）。

## 已知限制

- **样本量是根本约束。** 132 个训练样本不能支撑任何高容量模型，这也是深度方法在这批数据上没有优势的原因。
- **回归任务的形式值得重新考虑。** 用分类型的少量特征去拟合连续梯度，天花板可能是问题定义带来的，
  而不是方法不够好。有序回归或多任务学习是更合适的形式。
- **特征选择目前只在训练折内做，但超参调优不是完全嵌套的。** 若要把调优后的数字写进论文，需要改成嵌套交叉验证。
- **空间折本身是近似的。** KMeans 分块是一种简化，块的边界带有主观性；k 取 8/10/12 的结果已做过敏感性检查。
- **33 个封存测试样本至今未使用。** 按项目约定，探索阶段的结论不进正式报告，
  封存集只在确认阶段评估一次。
