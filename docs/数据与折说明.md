# 数据与折的说明

## 字段

原始文件 `data/raw/Wheat_Scab_Features_Extraction_Ordered_region.csv`，GBK 编码，165 行 × 126 列。

前 9 列是元信息，第 10 列起为 117 维特征。脚本统一用 `df.columns[9:]` 取特征，
所以前 9 列的位置和数量不能变，否则特征会错位。

| 列 | 含义 |
|---|---|
| `O_Name` | 采集人标识。发布版已匿名化为 `Rec_001`–`Rec_165` |
| `O_Comment` | 生育期与作物状态，例如「灌浆中期，病害 75%」 |
| `Unnamed: 2` | 标签，0 = 健康（90 例），1 = 患病（75 例） |
| `DI` | 病情严重度，0–100，人工目视估读 |
| `O_Lat` / `O_Lng` | 采样点纬度 / 经度 |
| `O_Alt` | 全为 0 |
| `O_TxtType` | 全为 0 |
| `O_Flag` | 采集人编码。发布版已映射为 `Group_A`–`Group_D` |

关于 `O_Name`：它的取值形如「姓名-编号」，是**采集人姓名加样本序号**，
既不是地块标识，也不是农户标识。数据里**不存在任何显式的田块或区域编号**，
唯一的空间信息是经纬度。所以做分组分析时分组变量只能从经纬度聚类导出，
不能拿 `O_Name` 或 `O_Flag` 当分组用。

标签与 `DI` 的关系是硬阈值：`DI ≤ 30` 记为 0，`DI ≥ 35` 记为 1，中间没有样本。
也就是说分类标签完全由 `DI` 决定，两者是同一个量的不同粒度。

## 划分

`src/create_split.py` 固定用 `train_test_split(test_size=0.20, random_state=42, stratify=标签)`，
得到 132 训练 + 33 封存测试。测试集在探索阶段全程不读，只做存在性检查。

`src/create_cv_folds.py` 在训练集内生成两套随机折：

- 分类：`StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`；
- 回归：先取 `DI > 0` 子集（116 行），再 `KFold(n_splits=5, shuffle=True, random_state=42)`。

回归为什么要先筛子集：DI = 0 的样本有 16 个，如果直接对 132 行做 KFold，
会出现某一折全是健康样本的情况，R² 没有意义。

## 空间折

空间折的做法是先按位置分块、再整块留出：

```python
blocks = KMeans(n_clusters=10, n_init=10, random_state=seed).fit_predict(coords)
fold = StratifiedGroupKFold(n_splits=3, shuffle=True, random_state=seed).split(coords, y, groups=blocks)
```

用 3 折而不是 5 折，是因为 10 个空间块分到 5 折里会出现只剩两个样本的废折。
分区种子取 42 / 7 / 2026，报告里凡涉及空间折的数字都会注明是单种子还是 3 种子均值。

两个容易被忽略的地方：

1. 分类和回归的空间折不是同一套。分类用 132 行加分类标签；
   回归有两种形态，一种用 132 行加 DI 的三分位分箱，另一种对 116 行的 `DI > 0`
   子集重新聚类。它们的折号不能互相套用。
2. 空间块由经纬度决定，坐标精度会直接影响分块结果。

## 坐标精度与复现

发布版把经纬度圆整到 0.01 度（约 1 km）。圆整之后 KMeans 的结果会变：
seed = 42 时约 10% 的样本换到别的块，折分配跟着变；
seed = 7 和 2026 的划分结构不变。

所以如果拿公开数据直接跑空间折，得到的数字和报告里的对不上。解决办法是把
用高精度坐标算好的折分配一并发布，放在 `data/cv/spatial_folds_k10.csv`。
表里每个训练样本一行，列的含义：

| 列 | 含义 | 行数 |
|---|---|---|
| `Rec_id` | 训练样本的匿名号 | 132 |
| `label` | 分类标签 | 132 |
| `block132_s*` | 132 行上的空间块号 | 132 |
| `fold_clf_s*` | 132 行 + 分类标签的折号 | 132 |
| `fold_reg132_s*` | 132 行 + DI 三分位分箱的折号 | 132 |
| `block116_s*` | 116 行（DI>0）上的空间块号 | 116 |
| `fold_reg116_s*` | 116 行 + 分类标签的折号 | 116 |

后缀 `s*` 是分区种子。`src/spatial_folds.py` 会按调用场景自动选取对应的列，
选不到时返回 `None`，由调用方按坐标现算。

随机折不依赖坐标，只用公开数据就能跑出与报告一致的结果。

这张折表由 `tools/make_release_data.py` 生成，同一步里也完成去标识化处理。
脚本会自检：发布版与原始数据在标签列和全部 117 维特征上必须逐位一致，
只有身份字段和坐标精度被改动。
