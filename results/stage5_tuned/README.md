## 一、一句话结论

**把每个模型的超参从「出厂默认」换成「在 `current_2` 上专属调优的参数」之后，擂台结果依然是
分类 440 个挑战者 0 胜 / 132 平 / 308 负，回归 360 个挑战者 0 胜 / 0 平 / 360 负。**

- **分类**：调参确实有效（空间折平均 +0.0063，60.9% 组合为正），但**全部落在 MDD 之内 → 只能算平手**。
  最好的挑战者 `rfe_svm+NB@K10` 空间折 0.8200 vs 擂主 0.7961（Δ=+0.0240，MDD=0.0312）→ **TIE**。
- **回归**：调参**帮助巨大**（空间折平均 **+0.1683**，81.1% 组合为正），但**起点太低** ——
  360 个挑战者里空间折 R² **一个正的都没有**（最好 −0.0362），全部 LOSE。

> 用一句话给非专业的听众：**"把模型调到它在这份数据上的最佳状态，也还是打不过那两个特征。**
> **分类打成了平手，回归连门都没摸着。"**

## 二、为什么要做这个实验（它在回答什么问题）

阶段②（选择器动物园）里，`XGB` 在分类轨全场垫底、`PLSR` 在回归轨全场垫底、`SVR` 表现异常差。
这些模型都是**出厂默认超参**跑的。当时提出了一个很自然的反驳：

> **"会不会不是这些模型不行，而是我们根本没给它们调好参数？"**

阶段③（超参扫描）与擂主档案（`champion_profile`）确实证明了：
`SVR` 从默认 0.2604 调到 `C=100, ε=5` 后 → **0.4916**（从第 9 名变第 1 名）。**调参真的能翻转结论。**

所以阶段⑤ 是把这个反驳**彻底钉死**：

> **把 10 个分类模型 / 9 个回归模型的调优参数全部装上，重跑整个「选择器 × K」矩阵，逐条挑战 `current_2`。**

如果调优之后的挑战者**还是打不过**，那么我们就能确定地说：
**「打不过」不是调参不够的问题，是数据/口径本身的问题。**

## 三、★ 单一变量控制（本实验成立的前提）

阶段⑤ 与阶段②/④ 相比，**唯一允许变化的东西 = 模型超参的来源**。下表逐项说明：

| 环节 | 阶段②（随机折对照） | 阶段④（空间折对照） | 阶段⑤（本实验） | 是否变化 |
|---|---|---|---|---|
| 数据源 | `Wheat_Scab_Features_Extraction_Ordered_region.csv` | 同左 | 同左 | ❌ 不变 |
| 训练集 / 划分 | `train.csv` 132 行（`random_state=42`） | 同左 | 同左 | ❌ 不变 |
| 随机折 | `StratifiedKFold(5, seed=42)`（分类）/ `KFold(5, seed=42)`（回归） | 同左 | 同左 | ❌ 不变 |
| 空间折 | — | KMeans(k=10) 聚类 + 3 折，种子 42/7/2026 | 同左，逐字复刻 | ❌ 不变 |
| 选择器实现 | `selector_zoo.py`（11 分类 / 10 回归） | 同左 | 同左，直接 import | ❌ 不变 |
| K 网格 | (5, 10, 20, 30) | 同左 | 同左 | ❌ 不变 |
| 打分函数 | `clf_scores` / `reg_scores` | 同左 | 同左，直接 import | ❌ 不变 |
| **模型超参** | **出厂默认** | **出厂默认** | **★ 在 `current_2` 上调优后的参数** | ✅ **唯一变化** |

### 3.1 模型包装方式也必须逐字对齐（★ 本项目踩过的坑）

`run_selector_zoo.py` 的模型库里，**有些模型内部自带标准化**，有些不带：

```python
# 阶段② 的模型库（简化）
Pipeline([("sc", StandardScaler()), ("m", LogisticRegression(...))])   # LR / KNN / SVM / SVMLin
                                                                        # LDA / PLSDA / NB
                                                                        # Ridge / SVR / PLSR / ENet / GPR
RandomForestClassifier(...)                                             # RF / ET / XGB —— 裸估计器
```

阶段⑤ 用了**同一套包装规则**，定义在 `src/run_stage5_tuned_matrix.py`：

```python
PIPELINE_MODELS = {
    "clf": {"LR", "SVM", "SVMLin", "LDA", "PLSDA", "KNN", "NB"},
    "reg": {"Ridge", "SVR", "PLSR", "ENet", "KNN", "GPR"},
}
```

**为什么这行代码很关键？** 因为如果阶段⑤ 图省事，把调优后的 `LogisticRegression` 直接裸着喂进循环
（不包 `StandardScaler`），那么"标准化"这个预处理就被**偷偷删掉了** ——
表面上只是"换了超参"，实际上**连数据都换了**。这就是"单一变量控制"被破坏的最隐蔽形式。

> 📌 **可自学知识点**：`sklearn.pipeline.Pipeline`（把"预处理 + 模型"焊成一体，避免测试集信息泄露）、
> 标准化（standardization / z-score）为什么对 SVM / LR / KNN 必需、而对随机森林可有可无。

### 3.2 对调优参数的进一步限定（诚实声明）

- 调优参数是**在 `current_2` 这 2 个特征上**选出来的（来源：`champion_best_params.json`），
  然后**一路沿用到所有 K 和所有选择器**。
- **不是**"每个 (选择器, 模型, K) 各自调参"——那会引入 440 × 若干次独立调参，winner's curse 会失控。
- 因此本实验测的是：**"把模型调成它在这份数据上的最佳形态"能带来多少增益**，
  而不是"每个组合的最优上限是多少"。**这个选择是有意为之，且偏保守**（对挑战者不利的方向
  ——因为挑战者拿到的是别人家的超参，不是自己最优的）。

## 四、★ 自校验：证明"差的就是调参那一项"

要让"阶段⑤ − 阶段②"这个差有意义，必须先证明**阶段⑤ 的循环本身没写歪**。

`src/selfcheck_stage5.py` 做的事：**把调优参数换回出厂默认**（取超参网格的第 0 项），
用阶段⑤ 自己的循环重跑 k=10 切片，然后与阶段② 的正式输出**逐行逐位比对**。

真实命令与输出：

```bash
D:/Anaconda/python.exe src/selfcheck_stage5.py
```

```
[selfcheck] 用『出厂默认参数』驱动 stage5 循环，检查是否逐位复现 stage2 的 k=10 切片
[clf] rows mine=550 gold(k=10)=550 common=550 | max|delta| = 1.110e-16 (PASS)
[reg] rows mine=440 gold(k=10)=440 common=440 | max|delta| = 3.553e-15 (PASS)
RESULT: PASS -- stage5 loop is faithful to stage2
```

**1.1e-16 是双精度浮点的机器精度（machine epsilon 量级）**，意味着两套代码算出来的数字
在计算机能表示的范围内**完全相同**。

> 📌 **可自学知识点**：机器精度 / `numpy.finfo(float).eps`；为什么"两个浮点结果之差的绝对值
> 小于 1e-12"就可以当成"相等"；"确定性审计"（determinism audit）在机器学习实验中的必要性。

### 4.1 这个自校验抓出的两个真实缺陷（★ 本轮最大价值之一）

自校验第一次跑时**没通过**，暴露了两处跨阶段的口径不一致：

**缺陷 A：阶段⑤ 的循环喂原始特征，阶段② 的模型内部自带标准化**
- 症状：`clf max|delta| = 9.167e-01`（0.9 的差距，不可能是浮点误差）。
- 修复：把 7 个分类模型 / 6 个回归模型按 §3.1 的 `PIPELINE_MODELS` 包回 `Pipeline`。
- 结果：回归立刻降到 `3.553e-15`（PASS），分类降到 `5.952e-03`（仍有残留）。

**缺陷 B：`hyperparam_grids.build_clf` 的 SVM / SVMLin 用了 `probability=False`**
- 症状：只剩 5/550 行不一致，**且只在 `roc_auc` 上、只在 SVM/SVMLin 上**。
- 根因：`clf_scores` 里的 `roc_auc` 优先用 `predict_proba`；当 `probability=False` 时模型
  没有这个方法，代码退化成用 `decision_function` 的值当分数。两条路径**排序不同** → AUC 差 6e-3。
- 关键事实：**全项目其余 7 个脚本都用 `probability=True`，只有超参网格这个文件不是** ——
  这是历史遗留的真实不一致，不是本实验引入的。
- 修复（`src/hyperparam_grids.py`）：
  ```python
  if name == "SVM":                       # RBF kernel, the project's default
      return SVC(kernel="rbf", C=p["C"], gamma=p["gamma"],
                 probability=True, random_state=SEED)
  if name == "SVMLin":                    # linear kernel
      return SVC(kernel="linear", C=p["C"], probability=True, random_state=SEED)
  ```
- 影响范围：**只影响 `roc_auc`，不影响 `accuracy`**。
  因此擂主档案（`challenge_rules` 判定用的是 `accuracy`）**无需重跑**，逐位不变（见 §8）。

修复后：`max|delta| = 1.110e-16 (PASS)`。

> 📌 **可自学知识点**：`SVC(probability=True)` 内部会用 Platt scaling 做概率校准（代价：训练变慢）；
> `predict_proba` 与 `decision_function` 给出的排序在理论上可以不同；AUC 只关心排序，
> 所以"换一个分数来源"就等于"换了一个指标"。

## 五、擂主是谁（钉死 `current_2`）

擂主不是全矩阵冠军，而是**用户指定的标杆 `current_2`（NREDI1 + NDVIre2）在自己内部的最强形态**。

| 轨道 | 主指标 | 擂主组合 | 空间折得分 | 跨分区种子 std | **MDD** |
|---|---|---|---|---|---|
| 分类 | `roc_auc` | **`current_2 + SVMLin`** | **0.7961** | 0.0000 | **0.0312** |
| 回归 | `r2` | **`current_2 + XGB`** | **0.1215** | 0.0294 | **0.0480** |

### 5.1 ⚠️ 必须披露：「换个指标就换个擂主」

`current_2` 各模型在**空间折**下的均值（这是本项目最重要的诚实性证据之一）：

**分类（`current_2` 内部 10 个模型）**

| 模型 | accuracy | roc_auc |
|---|---|---|
| **NB** | **0.8141** ← accuracy 冠军 | 0.7908 |
| **SVMLin** | 0.8114 | **0.7961** ← roc_auc 冠军 |
| SVM | 0.8114 | 0.7890 |
| LDA | 0.8015 | 0.7740 |
| PLSDA | 0.8015 | 0.7740 |
| ET | 0.7934 | 0.7759 |
| RF | 0.7889 | 0.7915 |
| XGB | 0.7862 | 0.7905 |
| LR | 0.7807 | 0.7747 |
| KNN | 0.7482 | 0.6962 |

→ **NB 在 `accuracy` 上以 0.8141 领先（0.8141 > 0.8114 > 0.8023），但在 `roc_auc` 上只有 0.7908。**
**这是本项目第一次明确看到"朴素贝叶斯（Naive Bayes）摘冠"** —— 一个极其简单、几乎不需要调参的模型。

**回归（`current_2` 内部 9 个模型，`r2`）**

| 模型 | r2_mean |
|---|---|
| **XGB** | **0.1215** |
| ET | 0.0357 |
| RF | 0.0216 |
| KNN | −0.0170 |
| SVR | −0.0665 |
| ENet | −0.1064 |
| Ridge | −0.1103 |
| PLSR | −0.1126 |
| GPR | −0.1860 |

→ **只有 XGB / ET / RF 三个树模型站在 0 以上**，其余 6 个全负。

**这对论文/竞赛的含义**：报分类结果时，**必须同时报 `accuracy` 与 `roc_auc`**，
并说明主指标的选择依据。本报告统一**以 `roc_auc` 为主裁判**（小样本 + 类别略不平衡时，
AUC 比 accuracy 更能反映排序能力，且不受 0.5 阈值主观选择影响）。

> 📌 **可自学知识点**：accuracy / precision / recall / F1 / ROC-AUC 各自衡量什么；
> 为什么"类别不平衡"时 accuracy 会骗人；为什么 AUC 只依赖"排序"而与阈值无关；
> 朴素贝叶斯（Naive Bayes）的"条件独立"假设为什么在小样本高维下反而稳健（bias-variance 视角）。

## 六、擂台规则（判定三态）

`src/challenge_rules.py`：

```python
mdd = champ.mdd                       # ★ 门槛只由擂主决定
delta = float(challenger_mean) - champ.mean
if   delta >  mdd:  verdict = WIN
elif delta < -mdd:  verdict = LOSE
else:               verdict = TIE

MDD = max(2 * sqrt(2) * sigma_seed / sqrt(n_folds),    # 跨种子波动
          1.0 / n_valid_min)                            # 单样本分辨率下限
```

**`MDD` = 最小可分辨差（minimum detectable difference）**。含义：
"两个分数差多少，我们才敢说它们不是一回事？"

### 6.1 ★ 本轮修复的方法论错误：「翻车越狠反而越安全」

**修复前的错误写法**：
```python
mdd = max(champ.mdd, 2*sqrt(2)*challenger_std/sqrt(n_folds))   # ❌ 错误
```

**为什么错**：它把**挑战者自己的跨种子波动**也算进了门槛。后果是**反向激励**：

- 一个挑战者在不同分区种子上**忽高忽低**（std 很大，说明它压根不稳），
  门槛被抬得极高 → 即便它平均分**巨亏**，也会因为"落在门槛内"被判 **TIE（平手）**。
- 真实案例：回归某组合（`perm+Ridge@K30`）空间折 **R² = −2.1764**，跨种子 std = 1.2108，
  门槛被抬到 **2.83** → 一个**亏了 2.3 分的灾难性结果**被判成了 `TIE`。

**这种规则错得最阴险的地方**：它不是在某个角上算错，而是**把规则本身的方向搞反了**
——"表现越不稳定 → 越容易被判为没输"。如果不发现，回归轨会得出
"360 个挑战者里 218 个平手"这种荒谬结论。

**修复后**：
```python
mdd = champ.mdd                       # ★ 门槛只由擂主决定
```
挑战者的 std **只作为诊断信息披露**（写在 `challenger_std` 列里），**不参与判定**。

**修复前后判定对比**：

| 轨道 | 版本 | WIN | TIE | LOSE |
|---|---|---|---|---|
| 分类 | 修复前 | 0 | 331 | 109 |
| 分类 | **修复后** | **0** | **132** | **308** |
| 回归 | 修复前 | 0 | 218 | 142 |
| 回归 | **修复后** | **0** | **0** | **360** |

**合理性检查**：修复后"平手"的数量**大幅下降**（分类 331→132，回归 218→0）——
这符合直觉：**平手应该是"真的差不多"，而不是"因为自己太乱所以不算输"。**

**回归轨 TIE 归零**这件事本身就是一条结论：
**在跨区域口径下，360 个调优后的挑战者没有一个能靠近 `current_2+XGB`（0.1215）。**

## 七、结果


**最强的 10 个挑战者**（全部落在 MDD=0.0312 之内 → TIE）：

| 选择器 | 模型 | K | 空间折 | 随机折 | Δ vs 擂主 | 判定 |
|---|---|---|---|---|---|---|
| `rfe_svm` | SVM | 20 | 0.7652 | 0.7904 | −0.0308 | TIE |
| `lasso` | XGB | 10 | 0.7658 | 0.7917 | −0.0303 | TIE |
| `fs_cs` | LDA | 10 | 0.7661 | 0.8100 | −0.0300 | TIE |
| `mrmr` | PLSDA | 20 | 0.7663 | 0.7894 | −0.0298 | TIE |
| `fs_cs` | LDA | 5 | 0.7665 | 0.7881 | −0.0296 | TIE |
| `perm` | SVM | 20 | 0.7666 | 0.8224 | −0.0295 | TIE |
| `fs_cs` | PLSDA | 5 | 0.7670 | 0.7853 | −0.0291 | TIE |
| `stab_fscs` | SVMLin | 10 | 0.7676 | 0.7763 | −0.0285 | TIE |
| `stab_lasso` | NB | 5 | 0.7684 | 0.7559 | −0.0277 | TIE |
| `stab_lasso` | SVM | 30 | 0.7685 | 0.8071 | −0.0276 | TIE |

> 注意上表有个"排序陷阱"：按 Δ 排的"最强"榜单里，`rfe_svm+SVM@K20` 的 Δ 只有 **−0.0308**
> ——**它是"最接近擂主"的，但仍然比擂主低**。真正**分数翻过擂主**的组合在下面。

**每个 K 的榜首（按空间折绝对分数）**：

| K | 选择器 | 模型 | 空间折 | 随机折 | Δ vs 擂主 | 判定 |
|---|---|---|---|---|---|---|
| 5 | `lasso` | SVM | **0.8130** | 0.7931 | +0.0170 | TIE |
| 10 | `rfe_svm` | **NB** | **0.8200** | 0.8164 | +0.0240 | TIE |
| 20 | `enet` | **NB** | **0.8149** | 0.7951 | +0.0188 | TIE |
| 30 | `spa` | **NB** | **0.8045** | 0.7866 | +0.0084 | TIE |

**三条观察**：

1. **有 17 个挑战者的空间折 ≥ 0.80**（擂主 0.7961），最好 0.8200。
   → **确实存在"分数上翻过擂主"的组合**，但幅度（+0.0240）**小于 MDD（0.0312）**
   → 按规则**只能算平手**。这是规则在保护我们不被噪声骗。
2. **`NB` 在 K=10/20/30 三个档位都拿到榜首** —— 与 §5.1 的"NB 在 accuracy 上摘冠"呼应。
   **一个几乎不用调参的极简模型，在跨区域口径下反复出现在最前面。**
3. **按 K 看，判定分布几乎均匀**（K=5: 76 输/34 平；K=10: 78/32；K=20: 78/32；K=30: 76/34）。
   → 与阶段④b 的结论一致：**在这个降维空间里（K ≤ 30），空间泄漏几乎测不出来**，
   所以 K 的增减对判定没有结构性影响。

**分类的空间折 vs 随机折相关性**：Pearson r = **0.6869**
→ 随机折排名只能"大致"预示空间折排名，**不能替代**。这再次支持"两套口径必须并报"。

### 7.2 回归轨：全线溃败

```
[挑战|reg] 共 360 个挑战者 -> WIN=0 / TIE=0 / LOSE=360
```

Δ 分布：**min −2.2978 / max −0.1577 / mean −0.6151**（**全负**）。

**每个 K 的榜首**：

| K | 选择器 | 模型 | 空间折 | 随机折 | Δ vs 擂主 | 判定 |
|---|---|---|---|---|---|---|
| 5 | `spa` | ET | −0.1451 | 0.2647 | −0.2665 | LOSE |
| 10 | `lasso` | KNN | −0.1107 | 0.3828 | −0.2321 | LOSE |
| 20 | `lasso` | KNN | −0.0825 | 0.3470 | −0.2039 | LOSE |
| 30 | `lasso` | KNN | −0.0362 | 0.4263 | −0.1577 | LOSE |

**最关键的一行数字**：

```
REG: how many challengers with spatial>0: 0 / 360
REG: best spatial overall: -0.0362
```

→ **360 个调优后的挑战者，在空间折下 R² 一个正的都没有。** 最好的是 `lasso+KNN@K30` 的 **−0.0362**，
比"直接猜训练集均值"还差（R² < 0 的定义就是"不如用均值预测"）。

**再看随 K 变化的趋势（这是最值得写进论文的一条）**：
- K=5 → 榜首 −0.1451
- K=10 → −0.1107
- K=20 → −0.0825
- K=30 → **−0.0362**

→ **特征越多，回归的空间外推越接近 0（但仍为负）**。这与 FS-CS、阶段②、④b、对齐基准
**四处独立证据同向**：**特征集规模是跨区域不稳定的第一大通道。**

**回归的空间 vs 随机折相关性**：Pearson r = **0.6388**
→ 比分类还低。回归的随机折冠军（KNN 0.4263、PLSR 0.38+）在空间折统统变成负数，
**"开卷考试"效应在回归轨比分类轨严重得多**（KNN 靠邻居，而样本最近邻中位距离只有 45 m）。

## 八、调参效应：把模型调到最佳，到底买到了什么？

**调参效应 = 阶段⑤（调优）− 阶段②/④（默认）**，按 (选择器, 模型, K, 口径) 严格配对。

> ⚠️ **配对口径说明**：阶段② 只有随机折（`A_random`），阶段④ 只有空间折（`B_spatial_s42`）。
> 所以空间折效应 = 阶段⑤ − 阶段④，随机折效应 = 阶段⑤ − 阶段②。
> **阶段⑤ 只取单种子 `B_spatial_s42` 与 `A_random` 参与配对**（不用三种子均值），
> 否则"折的组成"也变了，就不是单一变量了。

### 8.1 分类轨：调参有效，但买得很少

| 口径 | 配对数 | 平均 Δ | 为正的比例 |
|---|---|---|---|
| **空间折** | 440 | **+0.0063** | **60.9%** |
| 随机折 | 440 | +0.0035 | 55.0% |

**按模型分解（空间折，`roc_auc`）**：

| 模型 | mean Δ | median | min | max |
|---|---|---|---|---|
| **PLSDA** | **+0.0511** | 0.0488 | −0.0237 | 0.1679 |
| SVMLin | +0.0433 | 0.0357 | −0.0119 | 0.1313 |
| XGB | +0.0416 | 0.0446 | −0.0123 | 0.0953 |
| ET | +0.0302 | 0.0243 | −0.0066 | 0.0877 |
| KNN | +0.0167 | 0.0146 | −0.0350 | 0.0684 |
| RF | +0.0156 | 0.0153 | −0.0136 | 0.0479 |
| NB | 0.0000 | 0.0000 | 0.0000 | 0.0000 |
| SVM | −0.0101 | 0.0080 | −0.2134 | 0.0570 |
| LR | −0.0463 | −0.0423 | −0.2023 | 0.0173 |
| **LDA** | **−0.0795** | −0.0808 | −0.2364 | 0.0246 |

**读法**：
- **`NB` 的 Δ 恒为 0** —— 因为朴素贝叶斯**几乎没有超参可调**（只有一个平滑项 `var_smoothing`）。
  这解释了为什么它在 §7.1 里"不调参就能夺冠"：**它本来就没有调参的余地**。
- **`PLSDA` / `SVMLin` / `XGB` 从调参里获益最多**（+0.04 ~ +0.05）。
- **`LDA` / `LR` 调参反而变差**（−0.08 / −0.05）。原因：它们是**线性模型**，
  超参网格里能调的只有少数选项，而**挑超参这个动作本身带 winner's curse**
  ——在 `current_2` 上挑中的超参，换到别的选择器/K 上就未必好。
  这也再次印证阶段③的结论：**"分类轨调优几乎买不到东西"**。

**按 K 分解**：{K=5: +0.011, K=10: +0.0073, K=20: +0.0037, K=30: +0.0031}
→ **K 越小，调参收益越大**。符合直觉：特征少时"模型怎么用这些特征"更重要。

### 8.2 回归轨：调参帮助巨大，但起点太低

| 口径 | 配对数 | 平均 Δ | 为正的比例 |
|---|---|---|---|
| **空间折** | 360 | **+0.1683** | **81.1%** |
| 随机折 | 360 | +0.0333 | 58.6% |

**按模型分解（空间折，`r2`）**：

| 模型 | mean Δ | median | min | max |
|---|---|---|---|---|
| **PLSR** | **+0.4043** | 0.3800 | −0.1680 | 0.9081 |
| KNN | +0.2992 | 0.2845 | 0.0591 | 0.6546 |
| Ridge | +0.2376 | 0.2409 | −0.1794 | 0.9974 |
| SVR | +0.1927 | 0.1954 | −0.0402 | 0.3332 |
| ENet | +0.1203 | 0.1173 | −0.2908 | 0.7661 |
| ET | +0.0994 | 0.0702 | −0.1912 | 0.5482 |
| GPR | +0.0656 | 0.0778 | −0.3885 | 0.2884 |
| XGB | +0.0517 | 0.0628 | −0.2128 | 0.3208 |
| **RF** | **+0.0441** | 0.0325 | −0.4212 | 0.4229 |

**读法**：
- **`PLSR` 的 +0.4043 是全场最大** —— 这直接回答了阶段③ 的遗留问题：
  "PLSR 垫底是因为它差，还是因为没调参？" 答案是：**PLSR 极度依赖调参**
  （默认 `n_components` 完全不对，最优值居然是 `n_components=1`）。
  即便如此，调优后的 PLSR 空间折还是负的 → **它是"模型本质"问题，不是调参问题**（与阶段③ 一致）。
- **`KNN` +0.2992、`Ridge` +0.2376、`SVR` +0.1927** —— 三个"靠距离/线性"的模型都大幅受益。
- **`RF` +0.0441 收益最小** —— 随机森林默认超参本就不差（而且它本来是阶段② 的回归冠军）。
- 注意 **`KNN` 的 min 是 +0.0591（全为正）** —— 调参让 KNN **在所有 360 个格点上都不变差**。

**为什么回归调参收益远大于分类？**
阶段③ 已经给出了根因：**目标变量 `DI` 是 0–100 的原始尺度**，
而 `SVR` 的默认 `ε=0.1` / `C=1` 是按"标准化后的目标"设计的 → **默认状态严重欠拟合**。
调参修正了这个尺度错配，所以收益巨大。分类轨的目标是 0/1，
默认超参本就在合理量级上，没有这种系统性错配 → 收益很小。

> 📌 **可自学知识点**：
> - 为什么把目标变量标准化（或调 `epsilon` / `C`）对 `SVR` 至关重要；
> - `PLSR` 的 `n_components` 与"主成分个数"的关系（偏最小二乘 / partial least squares）；
> - winner's curse（赢家诅咒）：在一堆候选里挑"最好"的，挑中的那个真实水平会被高估。

## 九、⚠️ 多重比较警告（必须写进论文的免责声明）

本轮做了 **440 次**（分类）与 **360 次**（回归）比较：

```
本次共比较 440 次；不做校正时，纯靠运气至少撞出一个'显著'的概率约 1.000；
Bonferroni 参考门槛 alpha' = 1.14e-04。
本次共比较 360 次；不做校正时，纯靠运气至少撞出一个'显著'的概率约 1.000；
Bonferroni 参考门槛 alpha' = 1.39e-04。
```

**翻译成人话**：如果按常规的 `p < 0.05` 判定"显著"，
那么在这 440 次比较里，**"至少出现一个假显著结果"的概率几乎是 100%**。
所以**绝对不能**拿着本实验的"最强 10 个挑战者"去写"我们找到了显著更优的组合"。

**本实验的定位因此是**：**探索（exploration）阶段的定向排查**，用来确认
"调参是不是能救回那些垫底模型" —— 结论是**不能**。这个结论是"方向性"的、稳健的
（因为它建立在"0/440 与 0/360"这种极端缺失上，不是靠某个边缘显著）。

**要给出可发表的"谁比谁显著更优"，必须在确认（confirmation）阶段**：
多种子（≥5）配对 CV + Wilcoxon 符号秩检验 + 置换检验 + 效应量 + Holm/BH 校正，
且**候选集必须先冻结**（按原理覆盖挑，不按分数挑）。这份清单在
`docs/确认阶段待办清单.md`，**按协议必须等用户明确宣布"探索结束"后才执行**。

> 📌 **可自学知识点**：多重比较问题（multiple comparisons）、Bonferroni 校正、
> Benjamini-Hochberg FDR、family-wise error rate（FWER）、p-hacking、
> 预注册（pre-registration）与"探索/确认"两阶段分离为什么是科研诚实性的核心。

## 十、诚实边界（本实验不能证明什么）

1. **单分区种子**：空间折只用了种子 42（配对需要与阶段④ 严格对齐）。
   换种子排序会不会变？**会**（阶段④/擂主档案已证明分区种子敏感）。
   → 本实验的"平手/落败"判定是**方向性**的，不是最终数字。
2. **单模型种子**：分类调优参数固定，未做"调参种子"重复。
3. **调优参数来自 `current_2`**：不是每 (选择器, 模型, K) 各自调优（有意为之，见 §3.2）。
   → 因此本实验测的是**保守下界**，不是各组合的上限。
4. **未做校正 / 未做检验**：见 §9。
5. **判定规则是本项目自定义的**（`challenge_rules.py`），不是学界标准；
   MDD 公式里的 `n_valid_min` 项是"单样本分辨率"的经验下限。
6. **空间折 R² 为负本身有争议**：Roberts et al. 2017 指出"空间外推"场景下，
   基于随机 CV 的期望表现可能**高估**模型的真实外推能力，
   因此空间折全面转负**可能偏悲观**。真实能力**在随机折与空间折之间**。
7. **`test_locked.csv` 未读** —— 按项目纪律，封存测试集只在确认阶段评一次。

## 十二、本阶段新增的三条结论（供论文/竞赛使用）

1. **调参救不了**。把 9 个回归模型、10 个分类模型全部换成在 `current_2` 上专属调优的参数后，
   分类 440 个挑战者 **0 胜**（17 个分数翻过擂主，但幅度 < MDD）、
   回归 360 个挑战者 **0 胜、0 平、且空间折 R² 全为负**。
   → **"打不过 `current_2`"不是调参不够，是数据/口径本身的问题。**

2. **调参收益通道是不对称的**：分类空间折平均 **+0.0063**（买得极少），
   回归空间折平均 **+0.1683**（买得极多）。根因是 **`SVR`/`PLSR` 一类模型对目标尺度极度敏感**
   （`DI` 是 0–100 原始尺度，默认超参按标准化目标设计 → 系统性欠拟合）。

3. **回归轨的"K 效应"再次确认**：榜首 R² 随 K 单调向 0 靠拢（−0.1451 → −0.0362），
   但**始终为负**。**特征集规模是跨区域不稳定的第一大通道** —— 这已是第五处独立证据。
