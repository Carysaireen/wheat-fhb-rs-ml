## 一、为什么必须做这件事：口径陷阱

你在确认阶段之前问的这个问题，本质上是科研里最容易被自己骗到的一步。

项目从 **2026-08** 的「最早基线」走到现在的「选择器动物园 + 超参扫描」，中间换过脚本、换过预处理写法、换过超参、甚至换过评价指标。于是：

```
表面上的"进步" = 真正的方法进步 + 代码差异 + 超参差异 + 折差异 + 指标差异
```

**直接拿两个在不同脚本里算出来的数字相减，得到的不是进步，而是这几样东西的混合物。**

更具体地说，这个项目里同时存在**三种"分数口径"**，它们彼此不可比：

| 口径 | 性质 | 能不能当"能力"看 |
|---|---|---|
| 随机折（random K-fold） | 验证样本和训练样本可能来自**同一片地** | ❌ 高估（空间泄漏） |
| 空间折（spatial block CV） | 整块留出，验证样本在**没见过的区域** | ✅ 更接近真实部署 |
| 调优后的"网格最优"（grid best） | 在**要考的那张卷子上**挑的答案 | ❌ 高估（赢家诅咒） |

所以本报告的做法是：**把两边都放进同一套折、同一套代码、同一套指标里重算一遍**，然后再比。

## 二、"最早基线"到底指什么：这里有两个版本，必须先分清

项目里叫"双特征 + LR"的东西出现过两次，**数字不一样**：

| 版本 | 出处 | 双特征 | 准确率 | 口径问题 |
|---|---|---|---|---|
| **v1（2026-03~04）** | `archive/v1_exploration/`，记于 `docs/复盘报告_小麦赤霉病特征降维与模型构建.md` | NREDI1 + NDVIre2 | **0.8242** | 用**全部 165 个样本**、无封存测试集、独立脚本 → **不可直接引用** |
| **v2（2026-08 之后）** | `results/traditional_baseline` | NREDI1 + NDVIre2（`current_2`） | **0.8046** | 132 训练样本 + 固定 5 折 + 折内预处理 → **这才是本文的比较基准** |

> 两者的 0.0196 差距**不是方法差异**，而是"样本范围 + 折法"差异。**本文的一切比较一律以 v2 口径为准**（`current_2 + LR = 0.8046`）。
> 你在别处若看到 0.8242，那是 v1 的数字，写论文时不要与 v2 的表格混用。

同理，v1 报告的「16 特征 + RF 回归 R² = 0.499」也不能直接当基准；v2 里对应的是 **`boruta_30 + RF = 0.4450`**。

**"最早基线"在本文中的定义（三个候选）**：

- 分类：`current_2 + LR`（0.8046）、`boruta_30 + SVM`（0.8048）、`all_117 + RF`（0.7595）
- 回归：`boruta_30 + RF`（0.4450）、`common_6 + RF`（0.4140）、`all_117 + RF`（0.3954）

## 三、方法：怎么保证这次比较是公平的

| 控制项 | 做法 |
|---|---|
| **折** | A_random5 = `data/cv/classification_folds.csv` 的固定分层 5 折；B_spatial3 = KMeans(k=10) 空间块 + `StratifiedGroupKFold(3)`，分区种子 42/7/2026（与 P0-②、FS-CS 完全一致） |
| **代码** | 复用 `src/run_selector_zoo.py` 的模型工厂与打分函数；默认模型定义与 `traditional_baseline_cv.py` **逐字一致** |
| **指标** | 分类 `accuracy`（与最早基线同口径）+ `roc_auc`；回归 `r2` / `rmse` / `mae` |
| **特征集** | 最早侧 = 固定全局集合（`current_2` / `common_6` / `boruta_30` / `all_117`）；当前侧 = 逐折选择（`relieff_10` / `fs_cs_10` / `cars_10`），**只在训练折 fit，无泄漏** |
| **超参** | 每个模型给两版：默认（与最早基线相同）与调优（`results/hyperparam_sweep/recommended_params.json`，带 `*`） |
| **唯一变量** | 换特征集 / 换模型 / 换超参时，折、种子、预处理流程全部不动 |

**★ 自校验（这一步是整张表的信任来源）**

| 校验项 | 我的复算 | 参考值 | 结果 |
|---|---|---|---|
| `current_2 + LR` @ A_random5 | **0.8046** | 0.8046（`traditional_baseline`） | ✅ 精确一致 |
| `current_2 + LR` @ B_spatial3（3 种子均值） | (0.8331+0.8058+0.7680)/3 = **0.8023** | 0.8023（`fs_cs_selection`） | ✅ 精确一致 |

**两个独立来源的最早基线数字都被逐位复现了 → 说明口径真正对齐了，这张表可以用。**

### 4.2 两个口径给出**不同冠军**

```
随机折冠军：relieff_10 + ET*   0.8197   → 空间折只剩 0.6722  ← 崩了
```

**同一个模型，两种折下排名完全颠倒。** 这不是噪声，是空间泄漏的直接后果：`relieff_10 + ET*` 在随机折里学到的东西，有相当一部分是"这块地长什么样"，换一块地就失效。

### 4.3 空间折的排名被"小特征集"垄断

空间折前 6 名里，5 个是 **K ≤ 10** 的组合，其中 2 个是**只有 2 个特征**的 `current_2`：

反过来，117 维的 `all_117 + *` 全部落在 0.71 以下。

### 5.1 完整对照（R²）

|---|---|---|---|---|---|

| **boruta_30** | **RF** | **30** | **0.4450** | −0.2121 | +0.6571 |
| relieff_10 | RF | 10 | 0.4407 | −0.3022 | +0.7429 |

（完整 85 行见 `headline_reg.csv`）

### 5.2 空间折下，**回归几乎全军覆没**

除了 2～6 特征的少数组合，**所有 10 维以上方案的 R² 都是负数**——意思是"还不如直接用训练集均值去猜"。这与 P0-②（回归 gap +0.69）和阶段④b（空间效应 100% 为正）完全一致。

**唯一保持正 R² 的，仍是最小特征集**：`current_2 + XGB*` **+0.069**、`current_2 + ET*` **+0.045**、`common_6 + ET*` +0.014。

### 5.3 ★ `KNN` 的"高 R²"是一个空间泄漏标本

`relieff_10 + KNN*` 随机折 R² = **0.5149（全场第一）**，空间折 = **−0.1371**。

原因很直观：**KNN 的全部本领就是"找最近的邻居"**。而本项目的数据**高度共址**（最近邻距离中位仅 ~45 m，149/165 个样本在 110 m 内就有邻居）。随机折下，验证集样本的邻居**几乎都在训练集里**，KNN 相当于"开了卷"。一旦按空间块留出，邻居全被拿走了，KNN 立刻失效。

→ **这条线索价值很高**：它说明 **KNN/native-邻域类模型在共址遥感数据上的随机折分数几乎不可信**，这也解释了为什么"换模型"带来的回归提升（RF→KNN）**不能当作真实进步**。

## 六、直接回答你的两个问题

### Q1：目前的回归组合是否优于最先的？

**分口径回答，不能一句话。**

**同区域口径（随机 5 折）——是的，但"进步"的来源不是特征选择。**

| 对比 | R² | 差值 |
|---|---|---|
| 最早：`boruta_30 + RF` | 0.4450 | — |
| 只换特征集：`relieff_10 + RF` | 0.4407 | **−0.004（没有提升）** |
| 换模型（不调参）：`relieff_10 + KNN` | 0.5019 | +0.057 |
| 换模型 + 调参：`relieff_10 + KNN*` | **0.5149** | **+0.070** |

→ **特征的替换（Boruta 30 维 → ReliefF 10 维）本身没有带来任何提升**（0.4450 → 0.4407）。
提升全部来自 **换模型 + 调参**。而第 5.3 节刚证明：这个换模型带来的提升，**很可能就是空间泄漏**。

**跨区域口径（空间 3 折）——没有，而且方向相反。**

- 最早的 `boruta_30 + RF`：−0.2121
- 当前的 `relieff_10 + KNN*`：−0.1371
- **唯一"能用"的是最小特征集**：`current_2 + XGB*` **+0.0690**

→ **结论：就"跨区域预测病害严重度"这个真问题而言，两年探索下来，最好用的仍是"极少数特征 + 简单模型"，而不是任何高维组合。**

### Q2：目前的分类模型是否能优于最优双特征 + LR？

**分口径回答。**

**同区域口径（随机 5 折）——略微是，但不显著。**

| 方案 | Accuracy |
|---|---|
| 最早：`current_2 + LR` | 0.8046 |
| 当前最优：`relieff_10 + ET*` | **0.8197** |
| 差值 | **+0.0151** |

**这个差值比测量刻度还小**：随机 5 折的每折验证集是 26~27 个样本，**1 个样本 = 0.037**。0.015 连半个样本都不到，而且没有做任何显著性检验。**不能宣称"超过了"。**

**跨区域口径（空间 3 折）——明确没有。**

| 方案 | Accuracy |
|---|---|
| 最早：`current_2 + LR` | **0.8023** |
| 当前最优：`relieff_10 + ET*` | **0.6722** |
| 差值 | **−0.1301（差 0.13！）** |

→ **在"跨区域"这个真正重要的口径下，双特征 + LR 打败了我们所有的后期方案。**
略好一点的只有 `common_6 + RF*`（0.8129，+0.011）和 `current_2 + SVM`（0.8090，+0.007）——**这两个也全都属于"最早基线家族"（6 维 / 2 维），不是后来新增的方法。**

## 七、主线新证据：gap 随特征数上升，而**模型容量是第二条独立通道**

把每个（特征集 × 模型）组合的 gap 对特征数画散点（图 `fig2_*.png`）：

| 任务 | Pearson r | 斜率 |
|---|---|---|
| 分类 | **+0.52** | +5.3e−4 / 特征 |
| 回归 | **+0.34** | +2.7e−3 / 特征 |

正相关，方向与 FS-CS 实验（gap 随特征数单调上升）一致。**但 r 只有 0.34~0.52，说明"特征数"只解释了一部分**——剩下的部分，来自**模型容量**：

同样是 `relieff_10` 这 10 个特征，换一个模型，gap 就变了方向：

| 模型 | 随机折 | 空间折 | gap |
|---|---|---|---|
| ET（300 棵无限深树） | 0.7812 | 0.6740 | **+0.1073** |
| RF（300 棵无限深树） | 0.7818 | 0.7174 | +0.0644 |
| XGB（300 棵 depth3） | 0.7744 | 0.7072 | +0.0672 |
| SVM（RBF） | 0.8123 | 0.7863 | +0.0260 |
| **KNN（5 邻居）** | 0.7744 | 0.8087 | **−0.0343** |

→ **容量越大（越能"记住"训练区域）的组合，越怕换区域。** 这给了一条可检验的预测：
**要跨区域稳，就要同时压"特征数"和"模型容量"。**

## 八、推荐组合（按部署场景分）

因为两个口径的冠军不同，**"最优"必须先定义问题**：

### 场景 A：同一片田、有历史样本（同区域泛化）

| 任务 | 推荐 | 成绩 |
|---|---|---|
| 分类 | `relieff_10 + ET*`（或更稳的 `relieff_10 + SVM`） | 0.8197（SVM 0.8123 但 gap 小 5 倍） |
| 回归 | `relieff_10 + KNN*` | R² = 0.5149 |

### 场景 B：新区域、无历史样本（跨区域泛化）★ 更接近真实部署

| 任务 | 推荐 | 成绩 |
|---|---|---|
| 分类 | `common_6 + RF*`（0.8129）或 `current_2 + LR`（0.8023，仅 2 特征、可解释性最强） | 二者统计上难分 |
| 回归 | `current_2 + XGB*` | R² = +0.0690 |

**给竞赛/论文的一句话建议**：把**场景 B** 当主口径来选方案——它更难、更诚实、也更难被审稿人一句话推翻（"你的随机折高估了"）。`current_2 + LR` 这个"两年后的今天仍然打不过"的朴素解，反而本身就是一个**可写的故事**：*在空间分块验证下，极低维、可解释的特征集始终优于高维复杂模型*。

## 九、诚实边界（写进论文前必须知道）

1. **单模型种子**（42）+ **3 个空间分区种子**（42/7/2026）→ 数字仍带随机性；本文差异**未做显著性检验**，也未做多重比较校正（73/85 个组合一起看，赢家诅咒必然存在）。
2. **空间 3 折每折样本很少**（分类 32~53，回归 23~48）→ 单点准确率的最小刻度约 **1/40 ≈ 0.025**，任何小于它的差异都不该被解读。
3. **调优超参的"诚实值"是事后估计（LOFO），不是嵌套 CV**；若写进论文的最终超参必须改用嵌套 CV 重算。
4. `current_2` / `common_6` / `boruta_30` 是**全局固定**特征集（在整个训练集上定好），严格说不算 nested；但它们本来就是"最早基线"的形态，这里保留原样才可比。
5. **`current_2 + PLSR` 报错**（`n_components=5 > n_features=2`）——这不是 bug，而是提示 PLS 在 2 特征上无法用 5 个成分；该单元已跳过。
6. 全程**未读** `test_locked.csv`。

## 十、可自学知识点（供自行检索）

| 术语 | 中英 | 为什么这里重要 |
|---|---|---|
| 口径对齐 / 受控对比 | protocol alignment / controlled comparison | 让不同时期的数字可比，是本文全部结论的前提 |
| 空间块交叉验证 | spatial block CV / blockCV | 唯一能暴露"空间记忆"的评估方式 |
| 空间自相关 / 空间泄漏 | spatial autocorrelation / leakage | 样本越共址，随机折越乐观 |
| 赢家诅咒 | winner's curse | 在 N 个组合里挑最好 → 分数必然高估 |
| 训练集规模与学习曲线 | learning curve | 5 折 vs 3 折的训练量差异（已由阶段④b 剥离） |
| 模型容量 | model capacity | 与特征数并列的第二条泄漏通道 |
| 最近邻类模型在共址数据上的偏置 | spatial bias of kNN | KNN 在随机折下被"邻居开卷" |
| 决定系数 R² 为负的含义 | negative R² | 比"用均值预测"还差，说明模型外推失败 |
| 特征集规模 vs 泛化 | feature-set size & generalization | 全项目的主线变量 |
| 全局特征集 vs 折内选择 | global vs nested feature selection | 前者偏乐观，后者才无泄漏 |
