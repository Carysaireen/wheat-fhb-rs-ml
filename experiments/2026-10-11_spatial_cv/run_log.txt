  预处理：复用 preprocessing.build_preprocessor(clip_outliers=True)，经 Pipeline 绑定，
          只在训练折 fit（无泄漏）。模型同 traditional_baseline_cv.py。

  ── 主结果（k=10, 3 折, 3 seeds 均值）──
    task          model  metric  A_random  B_spatial   gap
    classification  LR   acc     0.7125    0.5881     +0.1244
    classification  RF   acc     0.7521    0.6792     +0.0729
    classification SVM   acc     0.7826    0.7293     +0.0534
    regression      RF   R²      0.3942   -0.2957     +0.6900
    regression   Ridge   R²      0.0724   -1.4813     +1.5537
    regression     SVR   R²      0.1690   -0.7374     +0.9064

  ── k 敏感性（分类 gap）──
    k=8 : LR +0.089 / RF +0.104 / SVM +0.118   （B 全折异常低）
    k=10: LR +0.124 / RF +0.073 / SVM +0.053   （主口径）
    k=12: LR +0.117 / RF +0.088 / SVM +0.071
  → 三种 k 结论一致：分类准确率 B 比 A 低 5–13 个点。

  ── 回归：失效更严重 ──
    空间折下 R² 全面转负（RF -0.30 / SVR -0.74 / Ridge -1.48），
    远低于随机折（0.39 / 0.17 / 0.07）。gap 高达 +0.69 ~ +1.55。

  ★ 结论：现有随机 CV 数字存在显著空间泄漏（乐观水分）。
    - 分类：准确率乐观约 5–13 个百分点；
    - 回归：随机折的 R²≈0.39 在空间外推下不成立（转负），
      R² 的真实泛化能力被严重高估 —— 与 Morellos 2025「R² 0.71→1.00」同类现象。
  ★ 注意（诚实性）：空间折 R² 转负，部分是「观测空间太小 + 块间类别不均衡」导致的外推
    困难（Roberts 2017 警告的偏保守方向）。故应两者并报，区间内取真值。

  产出：outputs/ 下 per_fold_metrics.csv / summary_metrics.csv / gap_table.csv /
        fold_design.csv / spatial_blocks.csv（另存 gap_table_k8.csv、gap_table_k12.csv）
