【1】发现隐藏随机性 → 重跑阶段①

  症状：阶段②（K=5/10/20/30）跑完后做回归校验 —— 其中 k=10 那一片本应与
        阶段①逐行一致（同数据/折/种子/网格），结果 550 行里有 8 行对不上，
        全在分类轨的 lasso 选择器、全在 fold=3，量级 1~2 个样本。

  排查：回归轨 450 行完全一致（max|Δ|=0）；
        同一份数据连续拟合 4 次 liblinear → top-10 顺序出现 3 种（不确定）；
        同一份数据连续拟合 4 次 saga+random_state=0 → 4 次完全相同（确定）。

  根因：sklearn 的 liblinear 求解 L1 逻辑回归时用「随机坐标置换」加速收敛，
        且不暴露随机种子；其随机数来自 C 标准库 rand()，状态是进程级全局的。
        阶段①只跑 k=10 一轮、阶段②要跑 4 轮 → 同一 fold 内的调用次序不同 →
        全局状态不同 → 收敛到「数值等价但排序不同」的解。
        本项目按 |coef| 取 top-k → 排序变则特征集合可能变 → 下游准确率变。

  处置：selector_zoo.py 顶部新增 L1_SOLVER='saga' / L1_SEED=0 /
        L1_MAX_ITER=3000 / L1_TOL=1e-3；三处 L1 调用统一（select_lasso 分类支、
        select_enet 分类支、_lasso_fast 分类支）全部改用它。
        实测：tol=1e-3 下 L1/elasticnet 均 ~370–430 次迭代收敛（<0.05s），
        max_iter=3000 是余量；修复后分类轨收敛警告 = 0。
        （遗留：回归轨 LassoCV 有 73 条 duality-gap 精度提示，但那是确定性
          坐标下降，不影响可复现性，保留原设置。）

  新增审计脚本：
    src/selfcheck_determinism.py   —— 阶段①顺序 vs 阶段②顺序，k=10 是否逐位相同
                                      （修复后两轨全部 SAME → PASS）
    src/verify_stage2_vs_stage1.py —— 阶段② k=10 与阶段①逐行回归校验
                                      （重跑后 1166 行 max|Δ|=0.000e+00 → PASS）

  重跑：阶段① 291 s，阶段② 505 s。
  留档：修复前结果备份于 outputs/_pre_fix_liblinear/。

★★ 阶段④ 运行记录（2026-10-12 23:45–23:51）：空间块交叉验证
================================================================================

【为什么做】随机折会把同一田块的样本同时放进训练与验证 → 空间泄漏抬高分数。
  项目已确认：样本空间高度共址（最近邻中位 ≈45 m）、位置与病害状态强相关
  （存在全健康块 / 全患病块）。空间块折强制"整块留出"，是唯一的诚实性检验。

【命令】python -u src/run_selector_zoo.py --stage4     （本次新增的驱动模式）
        python -u src/analyze_stage4_spatial.py

【折协议】KMeans(n_clusters=10, n_init=10, random_state=42) on (O_Lat, O_Lng)
          + StratifiedGroupKFold(n_splits=3, shuffle=True, random_state=42)
          分类折在全部 132 行上建；回归折在 DI>0 的 116 行上**重建**（对齐 P0-②
          的 spatial_group_cv.py，保证两次实验同折）。
          ★ 只用一个分区种子（42），使模型种子与阶段②完全一致 → 单一变量对照。

【折设计审计】（先验证再跑，已确认 0 个块跨折）

            合计 302 s（5 分 10 秒）。

【★ 结果】gap = 指标(随机折) − 指标(空间折)，同一 (选择器, 模型, K)
  分类（accuracy，440 组合）：总体平均 gap +0.0171；278/440（63.2%）为正。
    Spearman(选择器秩_随机, 选择器秩_空间) = +0.745 (p=0.008) → 排名基本保持。
    分类最优 K 不变（随机折与空间折都在 K=20 最好）。
    模型：RF gap −0.0017（几乎不掉）；SVMLin +0.0384 / PLSDA +0.0280 掉最多。
  回归（R²，360 组合）：总体平均 gap +0.6131；**360/360（100%）为正**；
    空间折下 R² 几乎全负（K=30 平均 −0.43）。
    Spearman = +0.236 (p=0.511) → **选择器排名被完全洗牌**（relieff 第1→第7，enet 第7→第1）。
    回归最优 K **向小 K 移动**（随机折峰在 K=10~20，空间折 K=5 最好）。
    模型：Ridge +0.8373 / PLSR +0.7907 最怕空间；RF/ET 最稳。

  ★ 差中差校正（扣掉 random 自身的协议效应 → 「超额 gap」）：
      分类 baseline gap = +0.0156；excess：rfe_svm +0.0341（最乐观）、
        **relieff −0.0006（≈0 → 它的优势不是空间泄漏造出来的）**、spa −0.0267。
      回归 baseline gap = +0.5954；excess：**relieff +0.1209（最大 → 随机折优势含泄漏）**、
        stab_lasso +0.0915、enet −0.0725。

【⚠️ 局限（必须并报）】
  1. 协议不对称：随机 5 折（训练 ~80%）vs 空间 3 折（训练 ~67%）→ gap 里混入"训练量变少"。
     → ✅ 2026-10-13 已由阶段④b（3 折随机折对照）解决，结论见本文件末尾。
  2. 只 1 个分区种子 → 分区不稳定性未评估（属确认阶段）。
  3. Winner's curse：从 360/440 组合挑最佳必然高估；空间折下唯一 R²>0 的
     mrmr+线性模型@K=5（≈+0.10）只能当假设。
  4. 单 seed / 超参未调 / 未读 test_locked。

【为什么做】
  阶段④ 的两个协议同时变了两个东西：① 折怎么切（随机→空间块）② 切几折（5→3）。

【设计】
  新增第三条协议 A_random3 = StratifiedKFold(3, shuffle=True, random_state=42)
    分类轨：全部 132 行分层        → 折 44/44/44（每折 24 健康 + 20 患病），训练 88.0
    回归轨：DI>0 的 116 行上重建，同样按 0/1 标签分层
                                   → 折 39/39/38（每折 19-20 健康 + 20 患病），训练 77.3
  与空间折的训练量严格对齐：分类 88.0 vs 88.0；回归 77.3 vs 77.3（★ 对照成立的全部理由）
  模型种子 42、分区种子 42 均与阶段④ 相同 → 唯一变量 = "折怎么切"

  三项分解（恒等式精确成立）：
      total_gap   = A_random5 − B_spatial      ← 阶段④ 报的数
      depth_gap   = A_random5 − A_random3      ← 纯"折数/训练量"效应
      spatial_gap = A_random3 − B_spatial      ← ★ 固定折数下的空间效应（诚实数字）

【结果】
  分类（accuracy，440 组合）：
      total   = +0.0171 (p<1e-4)
      depth   = +0.0168 (p<1e-4，63.9% 为正)      ← ≈ total！
      spatial = +0.0002 (p=0.540，50.2% 为正)     ← ≈ 0（抛硬币）
      恒等式残差 max = 0.00e+00 ✅
      → ⚠️ **阶段④ 的分类 gap 基本全部是"5 折变 3 折"，空间本身没有贡献**。
      → 在 K≤30 的降维空间里，分类随机折**没有可检出的空间泄漏**。
  回归（R²，360 组合）：
      total   = +0.6131 (p<1e-4)
      depth   = −0.0275 (p=1.00，31.9% 为正)      ← 方向相反（训练量效应不存在）
      spatial = +0.6407 (p<1e-4，**100.0% 为正**) ← ≈ total！
      恒等式残差 max = 2.22e-16 ✅
      → **阶段④ 的回归结论被坐实并加强**：gap 100% 由空间造成。

  baseline（`random` 选择器自身的协议效应）：
      分类 depth +0.0141 / spatial +0.0015；  回归 depth −0.0356 / spatial +0.6310

  ★ 超额 gap（扣掉 random）—— 固定 3 折口径下的空间项：

【★ 连带修正了阶段④ 的三条表述】
  1. 「分类存在空间泄漏」→ 降级为「分类 gap = 折数效应」。
  2. 「分类选择器排名基本保持（Spearman +0.745, p=0.008）」→ 固定 3 折后只剩
     **+0.400 (p=0.223)**。两个口径相差这么多，说明 11 个点的秩相关 CI 极宽，不宜当证据。
  3. 「分类 gap 随 K 下降（K=10 最大）」→ 那是折数效应（depth gap 随 K 降），空间项始终 ≈ 0。
  ✅ 但回归侧三条（崩塌 / 排名洗牌 / 最优 K 移向小 K）全部加强。

【为什么与 P0-② 的「分类 gap +0.124」不矛盾】
  P0-② 喂给模型的是固定的大特征集（上百维），本实验先做特征选择、K ≤ 30。
  模型容量越大越能"记住"训练区域 → 泄漏随特征集规模放大。
  这与 FS-CS 实验「gap 随特征集规模单调上升（2 特征≈0；117 特征≈0.06~0.10）」完全同向。
  → 正确表述：**在 K≤30 的降维空间里分类测不出空间泄漏**；维度上去后才显现。
