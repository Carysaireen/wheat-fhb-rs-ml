------------------------------------------------------------------------------

[5] ★ 判定规则修复：challenge_rules.py 的 MDD 门槛语义
------------------------------------------------------------------------------
错误写法（修复前）:
  mdd = max(champ.mdd, 2*sqrt(2)*challenger_std/sqrt(n_folds))
  后果 : 「翻车越狠反而越安全」—— 挑战者在不同分区种子上忽高忽低（std 大）会把门槛
         抬得极高，即便平均分巨亏也被判 TIE。
  实例 : 回归 perm+Ridge@K30 空间折 R2 = -2.1764，跨种子 std = 1.2108，门槛被抬到 2.83
         -> 亏了 2.3 分的灾难性结果被判成 TIE。

正确写法（修复后）:
  mdd = champ.mdd                # ★ 门槛只由擂主决定
  delta = challenger_mean - champ.mean
  WIN if delta > mdd ; LOSE if delta < -mdd ; else TIE
  挑战者 std 仅作诊断披露（challenger_std 列），不参与判定。

修复前后判定对比:
  轨道   版本      WIN   TIE   LOSE
  clf    修复前      0   331    109
  clf    修复后      0   132    308
  reg    修复前      0   218    142
  reg    修复后      0     0    360

合理性检查：修复后「平手」数量大幅下降（331->132、218->0），
符合直觉 —— 平手应是「真的差不多」，而非「因为自己太乱所以不算输」。

[7] 结论
------------------------------------------------------------------------------
1. 调参救不了。
   分类 440 个挑战者 0 胜（17 个分数翻过擂主，但幅度 < MDD=0.0312 -> 只能算平手）。
   回归 360 个挑战者 0 胜 / 0 平，且空间折 R2 全为负（最好 -0.0362）。
   -> 「打不过 current_2」不是调参不够，是数据/口径本身的问题。

2. 调参收益通道不对称。
   分类空间折平均 +0.0063（买得极少），回归空间折平均 +0.1683（买得极多）。
   根因: SVR/PLSR 一类模型对目标尺度极度敏感（DI 是 0-100 原始尺度，
   默认超参按标准化目标设计 -> 系统性欠拟合）。
   附带: LDA/LR 调参反而变差（-0.0795/-0.0463）—— 线性模型可调空间小，
   且"挑超参"本身带 winner's curse。NB 的 Δ 恒为 0（本来就没有超参可调），
   解释了它为何「不调参就能在 accuracy 上夺冠」。

3. 回归轨的 K 效应再次确认（第五处独立证据）。
   榜首 R2 随 K 单调向 0 靠拢（-0.1451 -> -0.0362）但始终为负。
   特征集规模是跨区域不稳定的第一大通道。

[8] 诚实边界
------------------------------------------------------------------------------
- 空间折仅用分区种子 42（配对需要与阶段④ 严格对齐）-> 判定是方向性的。
- 单模型种子；未做调参种子重复。
- 调优参数来自 current_2，非每组合各自调优 -> 测的是保守下界。
- 未做多重比较校正 / 未做显著性检验。
- 判定规则为项目自定义；MDD 中 1/n_valid_min 项是经验下限。
- 空间折 R2 为负可能偏悲观（Roberts et al. 2017）-> 真值在随机折与空间折之间。
- test_locked.csv 未读（按纪律只在确认阶段评一次）。
