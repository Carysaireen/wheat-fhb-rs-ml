# Self-supervised Fusarium Head Blight Detection with Hyperspectral Image and Feature Mining

> **ArXiv**: [2409.00395](https://arxiv.org/abs/2409.00395) | **Authors**: Yu-Fan Lin, Ching-Heng Cheng, Bo-Cheng Qiu, Cheng-Jun Kang, Chia-Ming Lee

# 第二篇论文阅读笔记 — 基于端元提取与Top-K波段选择的自监督赤霉病检测

> [!note]
> **一句话总结**：本文提出一种**无需GPU和深度网络的自监督赤霉病（FHB）检测方法**，通过K-means聚类生成伪标签引导Top-K波段选择，将筛选出的判别性波段作为端元特征，配合LightGBM/SVM等轻量分类器实现轻度与重度赤霉病的高精度区分，在Beyond Visible Spectrum: AI for Agriculture Challenge 2024竞赛数据上达到近乎完美的验证准确率。

---

## 核心架构

### 整体流程

```
输入HSI (101波段)
    ↓
[预处理] 归一化 + 光谱平均
    ↓
[伪标签生成] K-means聚类 (K=2, Elbow + Silhouette确定)
    ↓
[特征选择] Top-K波段选择（利用伪标签引导特征重要性挖掘）
    ↓
[特征表示] 选出的K个波段作为端元特征
    ↓
[分类] LightGBM / SVM（任意分类器均可）
    ↓
输出: mild-FHB / serious-FHB
```

### 各组件详解

#### 1. 预处理模块
- **归一化（Normalization）**：稳定训练和推理过程
- **光谱平均（Spectral Averaging）**：降低数据复杂度，去除噪声和冗余
- **设计动机**：FHB检测属于**粗粒度HSI分类**任务，无需保留细粒度特征

#### 2. 伪标签生成（K-means聚类）
- 利用归一化和光谱平均后的数据，K-means聚类效果显著提升
- **K值确定**：结合**肘部法则（Elbow Method）**和**轮廓分析（Silhouette Analysis）**两种方法
  - 肘部法则：绘制惯性（簇内平方和）随簇数变化的曲线，选取拐点
  - 轮廓分析：衡量样本与自身簇的相似度与其他簇的对比，取最高得分
  - **两种方法一致表明 K=2 为最优**（对应轻度/重度两类）

#### 3. Top-K波段选择
- **核心思想**：利用K-means生成的伪标签进行**特征重要性挖掘**
- 选出Top-K个最具判别力的波段作为端元
- **与传统端元提取的区别**：
  - 传统方法：基于优化算法，涉及密集的数学计算（如VCA、N-FINDR）
  - 本文方法：**直接提取判别性特征**，简化流程同时保持有效性

#### 4. 分类器
- **主分类器**：**LightGBM** — 擅长处理高维数据，效率高且鲁棒
- **对比分类器**：**SVM** — 用于全面分析
- **关键优势**：由于提取的特征鲁棒且紧凑，**分类器可以是任意的**

## 训练流程

### 数据描述

| 属性 | 详情 |
|------|------|
| 采集平台 | DJI M600 Pro UAV + S185快照式高光谱传感器 |
| 光谱范围 | 450-950nm，光谱分辨率4nm |
| 原始波段数 | 125波段 |
| 有效波段数 | **101波段**（去除前10和后14个噪声波段） |
| 飞行高度 | 60米，空间分辨率约4cm/像素 |
| 图像尺寸 | 全色图1000×1000px，HSI 50×50px |
| 训练数据划分 | 32×32块，带标签 |
| 数据集规模 | 共1,696个HSI（1,006个轻度FHB + 690个重度FHB） |
| 训练/验证划分 | 1,611训练 / 85验证 |

### 训练设置
- 分类器超参数：**全部使用默认设置**
- 数据增强：随机旋转、随机裁剪
- 评估指标：**准确率（Accuracy）**

$$ \text{Accuracy} = \frac{\text{TP}+\text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}} $$

## 关键实验结果

### Top-K波段数的影响

| K值 | 验证集准确率 |
|-----|------------|
| 3 | ~90% |
| 30 | **~100%（完美准确率）** |

> [!important] 关键发现
> - K=30时达到完美准确率
> - 即使仅选3个波段，准确率也接近90%
> - **波段数增加与准确率呈正相关**

### 重要波段的分布分析

- **关键波段并非均匀分布**，而是集中在特定波长范围：
  - **700-750 nm**（对应绿色光谱区域）
  - **800-875 nm**（对应红色光谱区域）
- **启示**：大部分高光谱数据对FHB检测可能是冗余的，有效利用这两个关键光谱区域的信息即可准确识别FHB

### 方法优势总结

1. **性能优异**：Top-30波段达到近乎完美的分类准确率
2. **计算高效**：显著降低数据维度（101→30），无需GPU
3. **可解释性强**：识别出的关键波段与植物生理特征（叶绿素吸收、红色边缘效应）相关联

---

## 创新点

1. **自监督/无监督范式**：利用K-means聚类生成伪标签，**完全摆脱人工标注依赖**
2. **轻量级部署**：无需GPU和深度神经网络，适合大规模农业应用
3. **简化端元提取**：用Top-K波段选择替代传统优化-based端元提取，**大幅降低计算复杂度**
4. **分类器无关性**：提取的特征鲁棒紧凑，可搭配任意分类器
5. **可解释性贡献**：揭示了FHB检测中关键光谱区域（700-750nm和800-875nm），为农业遥感提供生理学见解

---

## 局限性

1. **验证范围有限**：仅在单一竞赛数据集上验证（1,696个样本），**泛化性待检验**
2. **二分类局限**：仅区分轻度/重度FHB，未涉及健康/轻度/重度多分类场景
3. **K值敏感性**：虽然K=2由两种方法确认，但未讨论K值选择对结果的影响
4. **与深度学习方法对比缺失**：未与CNN等深度学习方法进行定量对比
5. **竞赛报告性质**：缺乏系统性消融实验（如不同聚类方法、不同特征选择策略的对比）
6. **空间信息未利用**：仅使用光谱信息，未充分利用HSI的空间-光谱联合特征

## 关键公式与算法总结

**准确率公式**：
$$\text{Accuracy} = \frac{\text{TP}+\text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}$$

**算法流程**（伪代码）：
```
1. 输入: HSI数据 X ∈ R^{N×B} (N样本, B=101波段)
2. 预处理: X_norm = Normalize(X), X_avg = SpectralAverage(X_norm)
3. 确定K值: Elbow Method + Silhouette Analysis → K=2
4. 伪标签: labels = KMeans(X_avg, K=2)
5. 特征选择: important_scores = FeatureImportance(X_avg, labels)
   selected_bands = TopK(important_scores, k=30)
6. 特征提取: features = X[:, selected_bands]
7. 分类: pred = LightGBM(features) 或 SVM(features)
8. 输出: mild-FHB / serious-FHB
```

---

## 与第一轮总结的整合

第一轮总结中提出的**方法定位**（对比传统方法与深度学习方法）在详细阅读后得到验证：本文方法确实在**硬件需求低、无需标注、可扩展性强**三个维度上具有显著优势。同时，第一轮总结中关于"端元提取与波段选择交互机制不明确"的疑问已得到解答——两者是**串联关系**，且端元提取被简化为直接使用Top-K波段作为端元特征。

## 这个项目做什么

小麦赤霉病（FHB）是世界性小麦病害。本项目针对遥感病害检测中最难的一类场景——**高维小样本（HD-SS）**：仅 165 个样本、117 维特征（植被指数 / 波段统计量 / GLCM 纹理），系统比较了「传统特征优选」与「深度表示学习（AE / GNN）」在两类任务上的表现：

1. **分类**：判断「健康 / 患病」；
2. **回归**：估计病情严重度 DI（有界连续量 [0,100]）。

**你能从这里得到什么**：一套可复现的「无泄露小样本建模」流程，以及一个关于「小样本下何时该用深度学习、何时不该用」的真实案例。

---

## 核心结果

> 所有数字均为**无泄露嵌套交叉验证**的严格结果，出处见 `results/` 下的指标 CSV。

| 方法 | 特征维度 | 分类准确率 | 回归 R²（DI） | 可解释性 |
|---|---|---|---|---|
| 传统特征 + 随机森林（Boruta 特征） | 30 | **≈0.79**（AUC 0.86） | **≈0.449** | ★★★ |
| 传统特征 + SVM / LR | 2–30 | ≈0.76–0.80 | 0.30–0.39 | ★★★ |
| AutoEncoder 2D + RF | 2 | ≈0.71 | ≈0.26 | ★☆☆ |
| 图神经网络（SageAE）2D + RF | 2 | ≈0.77 | ≈0.35 | ★★☆ |

**三个客观结论：**

1. **分类不需要深度学习** —— 少量红边指数即可达 ~0.80，且物理可解释；
2. **严重度回归是小样本硬天花板** —— 传统 RF 的 R²≈0.449 已是最优；
3. **朴素深度降维整体不如传统特征** —— 但归纳式 GNN（R²≈0.35）明显优于普通 AE（R²≈0.26），说明空间先验确有增益。

## 方法路线

```
第一阶段 · 传统特征优选
  Pearson 去冗余 + ReliefF + 随机森林重要性 + Boruta 三重过滤
  → 117 维 → 16 个核心特征 → 「黄金双特征」NREDI1 + NDVIre2

第二阶段 · 严重度回归探索
  直接回归 → 发现 DI=0 干扰 → 两阶段「先分类再回归」→ 纯患病样本回归

第三阶段 · 深度学习降维
  普通 AutoEncoder（117→2）  vs  图神经网络（光谱 + 空间建图，117→2）
```

---

## 科研规范

严格遵循 **无泄露（leakage-free）** 实验设计：

- 测试集**一次性封存**，探索阶段只用训练集及内部交叉验证；
- 按行分层的 `StratifiedKFold`（分类）/ `KFold`（回归）；
- 逐训练折**独立拟合**缺失值填补、标准化、AE / GNN 编码器；
- 深度表示学习采用**训练图 + 验证节点归纳式隔离**编码。

> 正是这套流程，让结论从初版探索期的乐观估计（分类 0.82 / R² 0.5）收敛到严格估计（分类 ~0.80 / R² 0.26–0.449）。**敢于用更严的方法推翻自己的漂亮数字，是本项目的核心价值。**

---

## GNN 的边界

GNN 是本项目试错成本最高的环节，前后经历两次修正：

- **初版建图不成立**：Haversine 硬阈值（≈55 米）在麦田级样本下使节点几乎全成孤点，GCN 退化为普通 MLP，空间信息基本未生效——这一缺陷被"83% 略胜 AE"的表面数字掩盖；
- **v2 用 KNN 重建图并真正修复了孤点问题**：图审计显示 K=5 时每个节点恰有 5 个邻居、0 个孤立节点，并采用 GraphSAGE 式归纳编码 + 验证节点隔离；
- **但建图仍依赖经纬度**，而数据存在 `O_Name` 历史重复记录，「经纬度 = 独立田块」的前提存疑。

结论：归纳式 GNN（回归 R²≈0.35）确优于普通 AE（R²≈0.26），空间先验有潜在价值；但受限于样本空间独立性的可靠性，**未作为最终采纳方法**。

---

## 进行中：改进方向

本项目是一个**仍在迭代的起点**。当前结论暴露了两条硬约束——**样本量** 与 **严重度回归的定义方式**：

**短期（可直接落地）**

- 回归问题重定义：DI 改**有序回归 / 多任务**，避免"用分类型特征拟合连续梯度"的天花板；
- 分类阈值优化：仅在训练集内确定阈值，观察 Recall / F1 / 校准；
- 完全嵌套特征选择：每个外层训练折内重新运行 Boruta。

**中期（需少量新数据 / 算力）**

- 自监督 / 对比预训练（ContrastBS、LMCN）利用无标签结构；
- GNN 升级：GAT + DropEdge、光谱相似度建边；
- 补充红边 / 红光指数。

**长期（高收益、有门槛）**

- 遥感基础模型微调（SatMAE / Prithvi）；
- 深度全特征回归（Deng et al. 像素级 DI 反演），把 R² 从 0.45 推向更高。

> 判断依据与领域调研见 `复盘报告_小麦赤霉病特征降维与模型构建.md`；决策推理与踩坑见 `docs/研究过程与方法论反思.md`。

# 小麦赤霉病特征降维与模型构建 · 项目复盘报告

> 复盘日期：2026-08-13
> 数据基础：`初版/Wheat_Scab_Features_Extraction_Ordered_region.csv`（165 个样本 × 117 个特征）
> 任务：① 二分类（健康 vs 患病）② 回归（病情严重度 DI，0–100）
> 说明：本报告基于 `初版/` 下 9 个 Python 脚本、6 个 CSV 中间产物、2 份「过程记录」docx 还原项目演进，并结合检索到的领域论文给出后续思路。

---

## 一、项目起源与定位

项目的起点是一张 **小麦赤霉病（Fusarium Head Blight, FHB）多光谱特征表**：特征由 Sentinel‑2 波段（B2–B12）派生，包含三类手工特征——

- **植被指数（VI）**：ARVI、NDVI、SIPI、DVI、TVI、EVI、OSAVI、RDVI、MSR、PSRI 系列、NDVIre 系列、NREDI 系列、REDSI 等；
- **波段统计量（MEA/VAR）**：各波段的均值、方差；
- **GLCM 纹理特征（HOM/CON/DIS/ENT）**：各波段灰度共生矩阵纹理。

目标很明确：**用尽量少的、可解释的特征，把"有没有病"判准，并把"病得有多重"估出来**。整个项目围绕"特征降维 → 建模 → 评估"展开，是一个典型的"高维小样本（HD‑SS）遥感农作物病害"问题。

---

## 二、技术演进时间线

| 阶段 | 核心动作 | 关键产出 | 主要结论 |
|---|---|---|---|
| **第一阶段** 传统特征优选 | Pearson 相关去冗余 + ReliefF + 随机森林重要性 + Boruta 三重过滤 | 从 117 维筛出 **16 个核心特征**，再提炼 **黄金双特征 NREDI1 + NDVIre2** | 双特征 + LR/SVM 交叉验证 **准确率 0.8242** |
| **第二阶段** 严重度回归探索 | 直接回归 DI → 发现 R² 低 → 试"先分类再回归"两阶段 → 剔 DI=0 做纯患病样本回归 | DI=0 干扰严重；剔除后 R² 从 0.61 降到 0.50（更客观） | **16 特征 + RF** 回归最佳 **R²≈0.499**；双特征回归 R² 仅 0.35 |
| **第三阶段** 深度学习降维 | ① 普通 AutoEncoder（117→2）② 图神经网络 GAE（光谱+空间经纬度建图，117→2） | AE 2D 特征；GNN 2D 特征（修正过平滑后） | GNN 分类 **83.03%**、回归 **R² 0.4815**，逼近 16 特征 RF；AE 不敌传统 |

### 关键结果汇总表

| 方法 | 特征维度 | 分类准确率 | 回归 R²（DI） |
|---|---|---|---|
| Baseline（全部 117 维） | 117 | — | — |
| Boruta 16 维 | 16 | ≈0.82 | **0.499**（RF） |
| 黄金双特征 NREDI1+NDVIre2 | 2 | **0.8242**（LR/SVM） | 0.3507（RF） |
| 普通 AutoEncoder 2D | 2 | 0.8061（RF） | 0.2852（RF） |
| GNN（GAE）2D | 2 | **0.8303**（RF） | 0.4815（RF） |

> 一句话总结你自己的过程记录：**分类任务不需要深度学习**（双特征已达 82.4% 且可解释）；**回归任务必须保留适度特征冗余**（16 维 ≈ 0.5），而朴素 AE 在小样本下反而更差。

---

## 三、关键决策的正确性评估

✅ **Boruta + 双重过滤**：用 ReliefF（实例距离）+ 随机森林（分裂增益）+ Boruta（影子特征）三重交叉验证，比单一方法稳健。你在笔记里还主动纠正了"按表格前 20 列画热力图"的不科学做法，改为算法驱动——这是很好的科研严谨性。

✅ **黄金双特征选在红边指数（NREDI/NDVIre）**：与 FHB 光谱机理一致（红光区与红边对赤霉病最敏感，见 Liu et al. 2020）。物理可解释、部署成本低，是论文里很吃香的卖点。

✅ **两阶段（先分类再回归）**：正确识别并缓解了 DI=0（健康样本）对连续严重度回归的干扰。

⚠️ **GNN 图构建粗糙**：仅用 Haversine 距离硬阈值建边，靠手工把 `distance_threshold` 从 0.005 砍到 0.0005 来压过平滑。这是"朴素版 DropEdge"，不是根本解法；且 GCN 无注意力，邻居等权聚合。

⚠️ **AE 目标与任务脱节**：用 MSE 重构损失，学到的"流形"未必对齐"疾病判别/严重度"语义，2D 压缩又丢信息——这是它不敌传统特征的根因。

---

## 四、瓶颈诊断：你到底卡在哪

把现象往根上挖，瓶颈其实是**三个叠加**：

1. **高维小样本（HD‑SS）天花板**：165 样本 / 117 特征，Hughes 现象明显。任何"从零训练"的深度模型都欠约束，AE 过拟合、GNN 过平滑都源于此。
2. **严重度连续回归本身难**：DI 有界 [0,100]、分布偏态、健康样本（DI=0）占大头。线性/树模型在"连续恶化梯度"上力不从心，R² 卡在 0.5 本质是**用 2 个分类型特征去拟合连续量**的方法天花板，而非调参问题。
3. **表示学习弱 + 评估单一**：AE 没用上"无标签结构"；评估只有 Accuracy / R²，缺混淆矩阵、每类指标、校准与不确定性，难以定位下一步。

> 本质：**不是方法不够多，而是 165 个样本撑不起高维深度模型，且"严重度"被当成普通回归定义了。**

---

## 五、相关论文与可借鉴思路（检索自 ArXiv / Remote Sensing / Computers and Electronics in Agriculture 等）

### 方向 1 · 用自监督 / 对比学习替换"朴素 AE + Boruta"
- **[arXiv:2409.00395] Self-supervised Fusarium Head Blight Detection with Hyperspectral Image and Feature Mining**（Lin 等, ICPR 2024 AI4Ag Challenge）— **同领域直接对标**。方法：HSI 端元提取（endmember extraction）+ top‑K 波段选择 + 自监督。可借鉴其"端元提取 + top‑K 选择"替代 Boruta，以及自监督预训练思路。代码已开源。
- **ContrastBS**（Li 等, *Remote Sensing* 2023, 15(23):5495）— 对比学习做**无监督波段/特征选择**，保留物理意义、免标签。比 Boruta 更可解释，正适合你 117 维特征。
- **SSCL：光谱‑空间对比学习波段选择**— 联合"光谱图"与"空间图"做对比，与你"光谱+空间"双特征设定天然契合。
- **LMCN：Lightweight Multiview Mask Contrastive Network**（PRCV 2023）— 掩码自编码器 + 对比学习，**专为小样本 HSI 设计**。可直接套你的 117 维特征做预训练，再接 RF/LR 头，预期超过 2D AE。

> 落地：**在 117 维上做对比/掩码自监督预训练 → 取编码特征 → 接分类/回归头**。这是对你 AE 最直接的升级。

### 方向 2 · 攻克严重度回归（你最明确的短板）
- **Deng 等 2023, "Pixel-level regression for UAV hyperspectral… wheat stripe rust DI"**（*Computers and Electronics in Agriculture*）— 像素级深度回归反演小麦条锈 DI，**R²=0.875**（HRNet + Laplacian 连续损失）。核心结论：**全波段端到端深度学习显著优于少量指数精简建模**（6 指数仅 0.829）。→ 你 2 特征回归 R²=0.35 是方法天花板，应上**深度全特征模型**。
- **RoViT-KAN（2026）**— 把病害严重度当**有序回归（ordinal）**而非普通连续回归，配不确定性估计，消融证明有序头显著提升 MAE。→ 你可直接把 DI 做 **ordinal regression** 或**多任务**（共享编码器 → 分类头 + 有序回归头），避免级联误差。

### 方向 3 · GNN 升级（你已踩到 DRFG 的门槛）
- **DRFG 出处**：Bhatti 等 2024, *Computers and Electronics in Agriculture* 226:109431 — "**dimension reduction fuzzy graph network**" = 3D‑CNN + **GAT** + PCA + FCM。这正是你 GNN 思路的源头。升级点：**用图注意力（GAT）替 GCN**，按"光谱相似度 + 空间邻近"加权建边，缓解过平滑且保留异质性。
- **DropEdge**— 随机丢边，原则性缓解过平滑（你手动调阈值≈其朴素版）。
- **MTGCN（ICML 2024）**— 多轨道消息传递，同时治过平滑与过碾压，可上更深 GNN。
- **建边改进**：用 KNN（光谱+空间）或注意力权重，取代纯 Haversine 硬阈值。

### 方向 4 · 跳出小样本——预训练 / 基础模型 / 数据增强
- **自监督 HSI 低秩多视角特征精炼**— 在**每类仅 5 个标签**的极端小样本下 OA 达 81–95%，证明无标签预训练增益巨大。
- **遥感基础模型**（IBM Prithvi、SatMAE、Clay）— 在大规模卫星语料预训练，微调你 165 样本。这是现代解法。
- **特征空间数据增强 / 伪标签 / Mixup**— 低成本扩充有效样本。

### 方向 5 · FHB 专属特征与波段选择
- **CARS‑Ridge**（ScienceDirect）— 竞争自适应重加权采样 + 岭回归，构造新指数 WFItwo/WFIthree，**有限数据下 91.4%**。CARS 是 Boruta 之外的强候选。
- **Liu 等 2020（Remote Sensing 12(22):3811）**— 红光区与红边对 FHB 严重度最关键，改进叶绿素吸收反射指数最优。→ 你的红边策略正确，可补充更多红边/红光指数。

---

## 六、推荐的下一步路线（按可行性排序）

**立即可做（低风险、复用现有代码）**
1. 用 ContrastBS / SSCL 思路做**对比式特征选择**，替代或补充 Boruta；
2. 严重度改 **ordinal regression / 多任务**（共享编码器 → 分类头 + 有序回归头）；
3. GNN 换 **GAT + DropEdge**，建边改 KNN（光谱+空间）。

**中期（需少量新数据/算力）**
4. 在 117 维上做 **掩码/对比自监督预训练**（LMCN 思路）再接头；
5. **CARS 波段选择** + 补充红边指数，验证是否超 Boruta 的 16 特征。

**高收益但有门槛**
6. **遥感基础模型微调**（SatMAE / Prithvi）迁移到你的 Sentinel‑2 特征；
7. **深度全特征回归**（Deng 思路）把 R² 从 0.5 推向 0.8+。

---

## 七、一句话复盘

> 你现在的天花板不是"方法不够多"，而是 **165 个样本撑不起高维深度学习 + 严重度被当普通回归定义**。突破口 = **自监督预训练（把无标签结构用起来）** + **重新定义回归问题（有序 / 多任务 / 深度全特征）** + **GNN 注意力化**。

# 步骤 1–4 执行记录

## 步骤 1：任务与指标

- 分类：`Unnamed: 2`（健康/患病），Accuracy、F1、Recall、ROC-AUC。
- 回归：`DI`（病害严重度），仅在 `DI > 0` 样本上建模，R²、RMSE、MAE。

## 步骤 2：样本独立性

数据共 165 行、117 个候选特征（第 10 列起）。经用户校正，每一行都是独立且不重复的数据对象，因此按行进行分层随机划分；`O_Name` 仅作为记录字段，不作为分组变量。

## 步骤 3：固定划分

按组进行约 80%/20% 划分，随机种子为 42，并同时保持分类标签分布尽量接近。具体组名和行号见 `data/splits/`。

## 步骤 4：测试集封存

测试集快照已单独保存。探索阶段不得使用测试集选择特征、预处理、模型、超参数或训练轮数；只有方案冻结后才进行最终测试。

# 步骤10：无泄露归纳式GNN

每个外层折只用训练节点的经纬度建立5近邻训练图，并仅用训练节点特征训练GraphSAGE式图自编码器。验证节点不进入训练图；模型冻结后，验证节点只读取5个最近训练节点的已学习表示进行归纳式编码，不能向训练节点传播信息。每折保存图规模、平均邻居数、孤立节点、训练损失和下游模型指标。测试集未读取。

本实现与原GCN全图转导式方案不同，重点是得到无泄露的开发阶段估计；K=5为预设值，后续若比较K值，必须在内层训练验证中选择。

# 步骤 6：无泄露预处理流程

## 数据审计

训练集含 132 行、117 个候选特征。未发现缺失值、无穷值或常量特征；IQR 规则标记出 754 个潜在异常单元格。异常值可能包含真实病害信息，因此不自动删除样本。

## 两套候选方案

1. 标准方案：训练折中位数填补 → 标准化。
2. 稳健方案：训练折中位数填补 → IQR 截尾 → 标准化。

两套方案将在后续训练集内部交叉验证中公平比较。当前不依据测试集作决定。

每一折都新建预处理器，只在该折训练部分执行 `fit`；验证部分只执行 `transform`。中位数、IQR 上下界、均值和标准差均不得由验证折或封存测试集贡献。

# 研究过程与方法论反思

> 本文档是对本项目「从探索到收敛」全过程的回顾，重点记录**决策背后的推理、踩过的坑与自我纠错**，
> 而非重复结果数字（结果见 `README.md` 与 `results/`）。所有陈述均可回溯到 `src/` 代码与 `results/` 指标文件。

---

## 一、起点：一个「看起来简单、实则处处是坑」的问题

项目的起点是一张 165 行 × 117 列的 Sentinel-2 派生特征表，任务有二：

1. 二分类——判断「健康 / 患病」；
2. 回归——估计病情严重度 DI（0–100 连续量）。

这是典型的**高维小样本（HD-SS）**问题。最危险的不是「模型不收敛」，而是**小样本下极易做出看似漂亮、实则泄露的假结果**。整个项目最核心的自觉，就是围绕这一点建立的。

---

## 二、第一次纠错：拒绝「为了画图而画图」

早期的特征相关热力图，直接按表格**前 20 列**截取绘制。这个做法被当场否定，理由写进了记录：

> 「按表格顺序截前 20 个画热力图是毫无科学根据的，仅仅是为了展示『代码能画热力图』。」

改为**算法驱动**：先用 Pearson 相关、ReliefF（实例距离）、随机森林重要性、Boruta（影子特征）四重交叉验证筛选，再对筛选后的特征画图。

**这条反思的价值**：它确立了项目的一条底线——**可视化和实验必须服务于科学问题，而不是演示代码能力**。这也是后来「无泄露重构建」的思想源头。

---

## 三、方法选择上的取舍：为什么最终是「传统特征 > 深度学习」

项目花了很大力气同时走两条路，最终结论偏传统：

| 路线 | 分类（准确率/AUC） | 回归（R²） | 结论 |
|---|---|---|---|
| 黄金双特征 NREDI1+NDVIre2 | 0.80 / 0.79 | 0.343 | 可解释性最强，分类足够 |
| Boruta 特征 + RF | 0.79 / 0.86 | **0.449** | 回归最优，保留适度冗余 |
| AutoEncoder 2D + RF | 0.71 | 0.26 | 欠约束，压缩丢信息 |
| 归纳式 GNN 2D + RF | 0.77 | 0.35 | 优于 AE，仍不敌传统 |

**关键判断**：

- **分类不需要深度学习**——两个红边指数（NREDI1 + NDVIre2）已能稳定到 ~0.80，且物理可解释；
- **回归必须保留适度特征冗余**——严重度是连续梯度，压到 2 维会损失信息，16–30 维的 RF 反而最好；
- **朴素 AE 在小样本下最差**——MSE 重构学到的流形与「疾病判别 / 严重度」语义不对齐，2D 压缩又丢信息。

---

## 四、最痛的一课：图神经网络（GNN）的两次试错

GNN 是本项目试错成本最高的环节，教训最值得记录。

### 第一次：初版的图「根本没建起来」

初版 `gnn_feature_extraction.py` 用 Haversine 距离**硬阈值 0.0005 弧度（≈55 米）**建边。但麦田级样本的样点间距通常在数百米到数公里，这个阈值下绝大多数节点沦为**孤点**，GCN 退化为一个「117→32→2 的普通 MLP 自编码器」。

表面看「GNN 83% 略胜 AE 80%」，实际**空间信息基本没生效**，差异更可能来自随机种子。这个假象之所以危险，是因为它「看起来合理」。

### 第二次：v2 真正修复了建图，但暴露出更深的问题

v2 的 `gnn_inductive_cv.py` 做了三件对的事：

1. 用 **KNN 建图**取代手工阈值——图审计（`results/gnn_inductive_cv/graph_audit.csv`）显示 K=5 时**每个节点恰有 5 个邻居、0 个孤立节点**，建图健康；
2. 用 **GraphSAGE 式归纳编码**（`s1(x) + n1(a@x)`）替代 GCN 的传递式聚合；
3. 做**训练图 + 验证节点归纳隔离**，避免测试信息混入表示学习。

修复后，归纳式 GNN（回归 R²≈0.35）**确实优于普通 AE（R²≈0.26）**，证明空间先验有潜在价值。

**但根本限制仍未解决**：建图依赖 `O_Lat / O_Lng` 经纬度，而数据存在 `O_Name` 历史重复记录，「经纬度 = 独立田块」的前提存疑。图的物理结构本身可能被污染——这是比「过平滑」更上游的问题。

### 结论

> GNN 如实记录为「优于 AE、但受限于样本空间独立性」的**有信息的负结果**，不采纳为最终方法。
> 正确方向：GAT + DropEdge 缓解过平滑、以光谱相似度而非纯经纬度建边、先核实样本独立性。

---

## 五、方法论的自觉：从「漂亮数字」到「诚实结论」

本项目最值得强调的，是一次**主动的自我推翻**：

- 初版探索期得到「分类 0.82、回归 R² 0.5」的乐观数字；
- 随后主动建立 `project_v2/`，用**无泄露（leakage-free）**流程重做：
  - 测试集**一次性封存**（`create_split.py`，20% 分层划分，`random_state=42`）；
  - 逐训练折**独立拟合**标准化、填补、AE / GNN 编码器；
  - 深度方法用**嵌套交叉验证**（外层评价 + 内层选超参）；
- 结果收敛到更保守的「分类 ~0.80、回归 R² 0.26–0.449」。

**这不是退步，而是更接近真实**。在 165 样本的规模下，敢于承认「深度学习不如传统特征」「GNN 受限于数据」，比报告一个漂亮的数字更需要科研诚实。

---

## 六、留下的方法论资产

1. **无泄露实验框架**：`create_split.py`（封存）→ `traditional_baseline_cv.py`（基线）→ `nested_*_tuning.py`（嵌套调优），构成可复用的 HD-SS 建模流程；
2. **特征选择的多方法交叉验证**：Pearson + ReliefF + RF 重要性 + Boruta，并记录各折稳定性（`results/feature_selection/feature_stability.csv`）；
3. **图神经网络的健康审计**：把「建图是否退化」作为独立检查项（`graph_audit.csv`），避免被表面指标误导；
4. **清晰的证据分级**（见 `docs/stage-summary.md`）：区分「直接支持」「合理推测」「尚待验证」。

---

## 七、如果重来一次，会改什么

1. **先核实样本独立性，再谈空间建模**——在碰 GNN 之前，先查清 `O_Name` 重复记录是否意味着样本非独立；
2. **回归问题先重定义，再选模型**——DI 有界、偏态、健康样本占大头，应优先考虑有序回归 / 多任务，而非在普通回归上调参；
3. **评估更全面**——补充混淆矩阵、每类指标、校准曲线与不确定性，而不只看 Accuracy / R²；
4. **把「负结果」当作一等成果来记录**——本项目最宝贵的发现（深度学习在小样本下不成立）恰恰来自一次负结果。

from pathlib import Path
import json
import numpy as np
import pandas as pd
from preprocessing import build_preprocessor

ROOT = Path(__file__).resolve().parents[1]
DATA = ROOT / 'data'
OUT = ROOT / 'results' / 'preprocessing'


def audit(task, data, folds, row_indices):
    features = data.columns[9:].tolist()
    rows = []
    for variant in ['standard', 'iqr_clip']:
        for fold in sorted(folds.fold.unique()):
            valid_rows = set(folds.loc[folds.fold == fold, 'row_index'].astype(int))
            valid_mask = np.array([idx in valid_rows for idx in row_indices])
            X_train = data.loc[~valid_mask, features].to_numpy(float)
            X_valid = data.loc[valid_mask, features].to_numpy(float)
            pipe = build_preprocessor(clip_outliers=(variant == 'iqr_clip'))
            Xt = pipe.fit_transform(X_train)
            Xv = pipe.transform(X_valid)
            rows.append({
                'task': task, 'variant': variant, 'fold': int(fold),
                'n_train': len(X_train), 'n_valid': len(X_valid),
                'train_missing_after': int(np.isnan(Xt).sum()),
                'valid_missing_after': int(np.isnan(Xv).sum()),
                'train_scaled_mean_abs_max': float(np.abs(Xt.mean(axis=0)).max()),
                'train_scaled_std_error_max': float(np.abs(Xt.std(axis=0) - 1).max()),
                'valid_abs_max': float(np.abs(Xv).max()),
            })
    return rows


def main():
    OUT.mkdir(parents=True, exist_ok=True)
    train = pd.read_csv(DATA / 'splits' / 'train.csv')
    cls_folds = pd.read_csv(DATA / 'cv' / 'classification_folds.csv')
    rows = audit('classification', train, cls_folds, train.index.to_numpy())

    sick = train[train['DI'] > 0].copy()
    reg_folds = pd.read_csv(DATA / 'cv' / 'regression_folds.csv')
    rows += audit('regression', sick, reg_folds, sick.index.to_numpy())
    report = pd.DataFrame(rows)
    report.to_csv(OUT / 'fold_preprocessing_audit.csv', index=False, encoding='utf-8-sig')

    X = train.iloc[:, 9:].apply(pd.to_numeric, errors='coerce')
    q1, q3 = X.quantile(.25), X.quantile(.75)
    mask = X.lt(q1 - 1.5 * (q3-q1)) | X.gt(q3 + 1.5 * (q3-q1))
    summary = {
        'n_training_rows': len(train), 'n_features': X.shape[1],
        'missing_cells': int(X.isna().sum().sum()),
        'infinite_cells': int(np.isinf(X.to_numpy()).sum()),
        'constant_features': int((X.nunique() <= 1).sum()),
        'potential_iqr_outlier_cells': int(mask.sum().sum()),
        'test_set_read': False,
        'policy': 'compare standard vs training-fold-only IQR clipping in later CV; never delete rows automatically'
    }
    (OUT / 'data_quality_summary.json').write_text(json.dumps(summary, ensure_ascii=False, indent=2), encoding='utf-8')
    print(report.to_string(index=False))
    print(json.dumps(summary, ensure_ascii=False))

if __name__ == '__main__':
    main()

def fit_encode(a,b,seed):

from pathlib import Path
import json
import pandas as pd
from sklearn.model_selection import StratifiedKFold, KFold

ROOT = Path(__file__).resolve().parents[1]
SPLIT_DIR = ROOT / 'data' / 'splits'
OUT_DIR = ROOT / 'data' / 'cv'

def main():
    OUT_DIR.mkdir(parents=True, exist_ok=True)
    train = pd.read_csv(SPLIT_DIR / 'train.csv')
    y_cls = train['Unnamed: 2'].astype(int).to_numpy()

    # Classification: same fixed stratified folds for every classifier.
    skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
    cls = pd.DataFrame({'row_index': train.index, 'fold': -1})
    for fold, (_, valid_idx) in enumerate(skf.split(train, y_cls)):
        cls.loc[valid_idx, 'fold'] = fold
    cls['label'] = y_cls
    cls.to_csv(OUT_DIR / 'classification_folds.csv', index=False)

    # Regression: rows are independent, so use ordinary fixed KFold.
    sick = train[train['DI'] > 0].copy()
    kf = KFold(n_splits=5, shuffle=True, random_state=42)
    reg = pd.DataFrame({'row_index': sick.index, 'fold': -1})
    for fold, (_, valid_idx) in enumerate(kf.split(sick)):
        reg.loc[valid_idx, 'fold'] = fold
    reg['DI'] = sick['DI'].to_numpy()
    reg.to_csv(OUT_DIR / 'regression_folds.csv', index=False)

    meta = {
        'random_state': 42,
        'n_splits': 5,
        'classification': {'method': 'StratifiedKFold', 'shuffle': True, 'fold_file': 'classification_folds.csv'},
        'regression': {'method': 'KFold', 'shuffle': True, 'fold_file': 'regression_folds.csv', 'filtered_condition': 'DI > 0'},
        'all_candidates_must_reuse_these_assignments': True,
    }
    (OUT_DIR / 'cv_metadata.json').write_text(json.dumps(meta, ensure_ascii=False, indent=2), encoding='utf-8')
    print(f'classification rows={len(cls)}, folds={sorted(cls.fold.unique())}')
    print(f'regression rows={len(reg)}, folds={sorted(reg.fold.unique())}')

if __name__ == '__main__':
    main()

from sklearn.metrics import accuracy_score, f1_score, recall_score, roc_auc_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

ROOT = Path(__file__).resolve().parents[1]
DATA = ROOT / 'data'; FS = ROOT / 'results' / 'feature_selection'; OUT = ROOT / 'results' / 'feature_set_cv'

def main():
    OUT.mkdir(parents=True, exist_ok=True)
    df = pd.read_csv(DATA / 'splits' / 'train.csv')
    folds = pd.read_csv(DATA / 'cv' / 'classification_folds.csv')
    all_features = df.columns[9:].tolist(); y = df['Unnamed: 2'].astype(int).to_numpy()
    stability = pd.read_csv(FS / 'feature_stability.csv')
    boruta = pd.read_csv(FS / 'boruta_stability.csv')
    sets = {
        'all_117': all_features,
        'current_2': [f for f in ['NREDI1','NDVIre2'] if f in all_features],
        'stable_rf_mi_3of5': stability.loc[stability.selection_rate >= .6, 'feature'].tolist(),
        'stable_rf_mi_4of5': stability.loc[stability.selection_rate >= .8, 'feature'].tolist(),

        'boruta_confirmed_5of5': boruta.loc[boruta.confirmed_rate >= 1.0, 'feature'].tolist(),
    }
    models = {
        'logistic_regression': Pipeline([('scaler', StandardScaler()), ('model', LogisticRegression(max_iter=2000, random_state=42))]),
        'svm_rbf': Pipeline([('scaler', StandardScaler()), ('model', SVC(kernel='rbf', probability=True, random_state=42))]),
        'random_forest': RandomForestClassifier(n_estimators=300, random_state=42, n_jobs=-1, class_weight='balanced'),
    }
    rows=[]
    for set_name, features in sets.items():
        X = df[features].to_numpy(float)
        for model_name, base in models.items():
            for fold in sorted(folds.fold.unique()):
                valid = folds.fold.to_numpy() == fold
                model = clone(base); model.fit(X[~valid], y[~valid])
                pred = model.predict(X[valid])
                score = model.predict_proba(X[valid])[:,1] if hasattr(model,'predict_proba') else model.decision_function(X[valid])
                rows.append({'feature_set':set_name,'model':model_name,'fold':int(fold),'n_features':len(features),'accuracy':accuracy_score(y[valid],pred),'f1':f1_score(y[valid],pred,zero_division=0),'recall':recall_score(y[valid],pred,zero_division=0),'roc_auc':roc_auc_score(y[valid],score)})

    summary.to_csv(OUT/'summary_metrics.csv',index=False,encoding='utf-8-sig')
    plt.figure(figsize=(11,6));
    for model in summary.model.unique():

"""Leakage-safe preprocessing shared by all later experiments."""
import numpy as np
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler


class IQRClipper(BaseEstimator, TransformerMixin):
    """Learn per-feature clipping bounds from training data only."""
    def __init__(self, factor=1.5):
        self.factor = factor

    def fit(self, X, y=None):
        X = np.asarray(X, dtype=float)
        q1 = np.nanquantile(X, 0.25, axis=0)
        q3 = np.nanquantile(X, 0.75, axis=0)
        iqr = q3 - q1
        self.lower_bounds_ = q1 - self.factor * iqr
        self.upper_bounds_ = q3 + self.factor * iqr
        return self

    def transform(self, X):
        return np.clip(np.asarray(X, dtype=float), self.lower_bounds_, self.upper_bounds_)


def build_preprocessor(clip_outliers=False):
    """Return an unfitted pipeline; it must be fitted inside each training fold."""
    steps = [('imputer', SimpleImputer(strategy='median'))]
    if clip_outliers:
        steps.append(('iqr_clipper', IQRClipper(factor=1.5)))
    steps.append(('scaler', StandardScaler()))
    return Pipeline(steps)

    names=df.columns[9:].tolist(); rf=pd.read_csv(FS/'feature_stability.csv'); bo=pd.read_csv(FS/'boruta_stability.csv')
    return {'all_117':names,'current_2':[f for f in ['NREDI1','NDVIre2'] if f in names],'common_6':['B8_HOM','B8_MEA','NDVIre2','NDVIre3','NREDI1','NREDI2'],'boruta_3of5':bo.loc[bo.confirmed_rate>=.6,'feature'].tolist()}

def main():
    df=pd.read_csv(DATA/'splits'/'train.csv'); sets=feature_sets(df); cls=pd.read_csv(DATA/'cv'/'classification_folds.csv'); y=df['Unnamed: 2'].astype(int).to_numpy(); cr=[]
    models={'LR':Pipeline([('scaler',StandardScaler()),('model',LogisticRegression(max_iter=2000,random_state=42))]),'SVM':Pipeline([('scaler',StandardScaler()),('model',SVC(kernel='rbf',probability=True,random_state=42))]),'RF':RandomForestClassifier(n_estimators=300,random_state=42,n_jobs=-1,class_weight='balanced')}
    for sn,fs in sets.items():
        X=df[fs].to_numpy(float)
        for mn,base in models.items():
            for fold in sorted(cls.fold.unique()):
                v=cls.fold.to_numpy()==fold; m=clone(base); m.fit(X[~v],y[~v]); pred=m.predict(X[v]); prob=m.predict_proba(X[v])[:,1] if hasattr(m,'predict_proba') else m.decision_function(X[v]); cr.append({'task':'classification','feature_set':sn,'model':mn,'fold':int(fold),'n_features':len(fs),'accuracy':accuracy_score(y[v],pred),'f1':f1_score(y[v],pred,zero_division=0),'recall':recall_score(y[v],pred,zero_division=0),'roc_auc':roc_auc_score(y[v],prob)})
    sick=df[df.DI>0].copy(); rg=pd.read_csv(DATA/'cv'/'regression_folds.csv'); rr=[]; yr=sick.DI.to_numpy(float)
    rmodels={'Ridge':Pipeline([('scaler',StandardScaler()),('model',Ridge(alpha=1.0))]),'SVR':Pipeline([('scaler',StandardScaler()),('model',SVR(C=1.0))]),'RF':RandomForestRegressor(n_estimators=300,random_state=42,n_jobs=-1)}
    for sn,fs in sets.items():
        X=sick[fs].to_numpy(float)
        for mn,base in rmodels.items():
            for fold in sorted(rg.fold.unique()):
                v=rg.fold.to_numpy()==fold; m=clone(base); m.fit(X[~v],yr[~v]); pred=m.predict(X[v]); rr.append({'task':'regression','feature_set':sn,'model':mn,'fold':int(fold),'n_features':len(fs),'r2':r2_score(yr[v],pred),'rmse':mean_squared_error(yr[v],pred)**.5,'mae':mean_absolute_error(yr[v],pred)})
    allr=pd.DataFrame(cr+rr); allr.to_csv(OUT/'per_fold_metrics.csv',index=False,encoding='utf-8-sig'); summary=allr.groupby(['task','feature_set','model'],as_index=False).agg(n_features=('n_features','first'),metric_1_mean=('accuracy','mean'),metric_1_std=('accuracy','std'),f1_mean=('f1','mean'),recall_mean=('recall','mean'),roc_auc_mean=('roc_auc','mean'),r2_mean=('r2','mean'),r2_std=('r2','std'),rmse_mean=('rmse','mean'),mae_mean=('mae','mean')); summary.to_csv(OUT/'summary_metrics.csv',index=False,encoding='utf-8-sig')
    for task,metric,title,path in [('classification','roc_auc_mean','Classification ROC-AUC','classification_baseline.png'),('regression','r2_mean','Regression R2','regression_baseline.png')]:
        s=summary[summary.task==task]; plt.figure(figsize=(10,6)); labels=s.feature_set+' | '+s.model; plt.barh(labels,s[metric]); plt.xlabel(metric); plt.title(title+' (training CV)'); plt.tight_layout(); plt.savefig(OUT/path,dpi=180); plt.close()
    print(summary.to_string(index=False))
if __name__=='__main__': main()
